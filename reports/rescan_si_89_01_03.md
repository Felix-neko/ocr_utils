## Как определялись выходные данные

Дата, номер выпуска и номер полосы взяты из колонтитула самой полосы, а не из имени файла:

* чётная полоса (`_2`) — внизу слева: `4 ● Социалистическая ИНДУСТРИЯ ● 22 января 1989 г. № 18 (5909)`;
* нечётная полоса (`_1`) — внизу справа: `24 марта 1989 г. № 69 (5960) ● Социалистическая ИНДУСТРИЯ ● 5`.

Читалось по JPEG-превью из RAF (`exiftool -b -PreviewImage`), ориентация кадра — из EXIF-тега
`Orientation` (нечётные полосы сняты с `Rotate 270 CW`, чётные — с `Rotate 90 CW`). Каждая строка
прочитана глазами по вырезке колонтитула: `tesseract` на этих кадрах не читается вовсе — это
самые расфокусные кадры подшивки, и он выдаёт по ним бессвязный набор букв.

Проверка на согласованность: сквозная нумерация и номер выпуска расходятся на постоянную
величину (5899 − 8 = 5891 для всех шести кадров), и промежутки между номерами совпадают с числом
выходов газеты между датами (по понедельникам не выходила). Значит, ни одна цифра не прочитана
неверно.
