# Финальные PDF пака-1: сборка из двух прогонов FineReader

Прогон `ocr_utils.final_pdfs` по паку-1 (2026-09-19). Выход — `/mnt/SYSTEM/raw/mts/pack1_pdf/final_pdfs/`
(123 файла `{год}/{год}_{выпуск}.pdf`, по папке на год, 1,80 ГиБ), рабочий каталог —
`/mnt/SYSTEM/raw/mts/pack1_final_pdfs_work/` (JSON анализа на страницу в `pages/`, `analysis.csv`,
`pages.csv` — 12 135 строк, `summary.csv` — 123 строки, `preview/` — 232 PNG страниц с иллюстрациями).

## 1. Задача

FineReader распознал промежуточные PDF пака дважды — с коррекцией геометрии и без. Коррекция
выправляет прогиб и перекос, но на части страниц гнёт линейки и чертежи; иллюстрации же можно
точно вернуть на место только в геометрию скана. Нужно собрать финальный PDF каждого выпуска
постранично из лучшего источника, починить текстовый слой (повёрнутый текст FineReader
распознаёт россыпью знаков, подписи на схемах и ячейки без слоя пропускает) и вернуть цветные
и серые иллюстрации из очищенных сканов верхним слоем JPEG.

## 2. Стенд и данные

* Вход: `GEO_PDF_DIR` / `NOGEO_PDF_DIR` (123 пары PDF, 12 135 страниц, JBIG2 600 dpi + слой),
  `BLURRED_DIR` (очищенные полосы TIFF 600 dpi — источник иллюстраций; заострённые копии не

## 3. Метод

По странице (`ocr_utils/final_pdfs`, подробности в README и докстрингах):

1. **Источник.** Растр в базе (`PICTURE_KINDS`) → без коррекции; иначе вердикт
   `ocr_utils.geometry_regression` из кэша (пороги v12 по умолчанию): `bad` → без коррекции,
   `mixed`/`ok` → с коррекцией. Привязка страницы к полосе — по порядку в базе, на страницах с
   иллюстрациями сверяется размер образа no-geo: полоса (повёрнутая на `rotate_cw`) + поля
   12,192 / 6,096 мм (288 / 144 px) — расхождение остановило бы выпуск.
2. **Слой** (`ocr_utils.text_layer_fix`): зоны повёрнутого текста и прямого без слоя, tesseract,
   вердикты по словам (пороги из `reports/text_layer_fix.md`; новое — числа без букв принимаются
   от 0,8 без ведущих нулей), surya по зонам с ненадёжным чтением; в слое: удаление `BT…ET`
   внутри спана, усечение, вставка невидимого текста Noto Sans в тот же поток.
3. **Иллюстрации**: вырезка из очищенной полосы по разметке, 600 → 300 dpi (Gaussian σ 0,05 мм +
   INTER_AREA), JPEG q75, серые одноканальные (`DeviceGray`), место = рамка + поля. FineReader
   кладёт фото отдельными JBIG2-образами (60–120 КБ), под ними основной образ пуст — такие образы
   (≥ 80 % площади внутри иллюстрации) снимаются; при полностраничном растре снимаются все.
4. **Сверка** по сохранённому файлу: оставленные глифы на местах, удалённые не извлекаются,
   вставки находятся `search_for`, основной образ не пересжат, JPEG нужной цветности на своём
   месте (±1 pt), число страниц.

## 5. Что пробовали и отвергли

* Затирание бинарного растра под иллюстрацией через перекодирование JBIG2 → CCITT G4 — G4 на
  40 % больше JBIG2, выигрыш от затирания ~1 КБ; вместо этого снимаются образы-фигуры FineReader.
* Иллюстрации из заострённых копий (Capture One) — заострение подчёркивает растровую сетку;
  из оригиналов «Готово» — там ещё рукописные надписи на 48 обложках; взяты очищенные полосы.
* Уменьшение 600 → 300 dpi одним INTER_AREA — сетка растра видна; Gaussian σ 0,1 мм уже мылит
  окна зданий на фото; σ 0,05 мм.
* Фильтр выдумок surya из `rotated_text` как есть — на слое пропускал латиницу без кириллицы
  («and special to», «THE PERSON NAMED IN», 66 из 514 принятых) и ряды одинаковых чисел
  («35 35 35 …», 5): добавлен свой фильтр (`text_layer_fix.second_opinion.hallucination_reason`),
  76 чтений снято, одна ненайденная вставка ушла.
* `full_pdf_page_idx` и поля выпусков из базы — после `from-cvat` они пусты; привязка по порядку
  полос со сверкой размера образа (0 расхождений на паке) надёжнее.

## 6. Доработки после первой сборки (пересборка `--reassemble`, 5 мин)

По замечаниям пользователя (2026-09-19, вечер):

* **Обложки без полей.** Страница с растром ≥ 97 % полосы (165 страниц) обрезается до полосы:
  JPEG режется по всей полосе, `MediaBox` = полоса, бинарного образа нет. Слова слоя FineReader,
  вылезающие за обрезанную страницу, ужимаются внутрь той же матрицей (пересечение рамки со
  страницей, не меньше 2 pt по стороне; целиком снаружи — полоска у ближайшего края): 90 слов на
  55 обложках, все находятся поиском в своих рамках. Проверка глазами: `preview/*_p001.png`.
* **Перенос по словам во вставках.** Вместо строк tesseract текст укладывается словами: перебор
  кегля от 10 pt вниз шагом 0,25 до наибольшего, при котором все строки помещаются и по длине, и
  по толщине зоны; строки tesseract не сохраняются. Пример: 1966/01 с. 76, ячейка «Специфицированная
  норма на условный сутко-комплект» — три строки вместо одной петитом; каждое слово ищется.
* Сверка при этом дала 3 ложные тревоги «удалённое слово на месте»: своя вставка (Noto) кладёт
  ту же букву на то же место, где стояла россыпь FineReader; символы своего шрифта из проверки
  удалённых исключены. После пересборки: 123 выпуска, сверка 0 расхождений, 1,80 ГиБ.
* `pages.csv`/`summary.csv`/`analysis.csv` при частичном прогоне сливаются с прошлыми записями,
  а не затираются.
