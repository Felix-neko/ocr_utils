В условиях устойчивого ассортимента текстильной продукции на предприятиях накоплен большой опыт по нормированию расхода сырья. Нормы расхода материальных ресурсов не являются стабильными и систематически пересматриваются на основе совершенствования технологии, организации производства и достижений передовиков.

Общая потребность в сырье определяется путем умножения нормы расхода на заданное количество продукции. Например, если на выработку 100 м миткаля норма расхода основной пряжи составляет 3,425 кг, уточной пряжи — 2,595 кг, а квартальный план производства миткаля установлен в 5 млн. м, то общая потребность в пряже составит

$$ \frac{(3,425 + 2,595) \cdot 5\,000\,000}{100} = 301 \text{ m.} $$

Для определения необходимого поступления сырья в производство нужно учесть изменение остатков незавершенного производства на начало и на конец планируемого периода.

На текстильных предприятиях для определения потребности в сырье каждого производства (прядение, ткачество, отделочное производство) составляют баланс сырья в производстве. Такие внутрипроизводственные балансы не следует смешивать с материальными балансами народнохозяйственного плана или планами материально-технического снабжения, которые разрабатываются по балансовому принципу непосредственно на предприятиях. Баланс сырья в производстве, указывающий остатки незавершенного производства, использование угаров, расход сырья, служит основой определения потребности предприятия в сырьевых ресурсах на предстоящий период.

Для пояснения порядка разработки приводим примерный баланс сырья в прядильном производстве[^1].

| | Показатели | Удельный вес, % | Количество, т |
|---|---|---|---|
| | **А. Ресурсы** | | |

| | в том числе хлопка | 92 | 184 |
| 2 | Поступление в прядильное производство за год: хлопка | 90,9 | 1863,5 |
| | оборотов и угаров | 9,1 | 186,5 |
| | Итого поступлений | 100 | 2050 |
| 3 | Всего ресурсов | 100 | 2250 |
| | в том числе хлопка | 91 | 2047,5 |
| | Израсходовано сырья в производстве: смеси | 100 | 2000 |
| | в том числе хлопка | 91 | 1820 |
| | **Б. Расход** | | |
| 1 | Получено из производства: пряжи | 85 | 1700 |

Выход пряжи из хлопка составит:

$$ B = \frac{1700 \cdot 100}{1820} = 93,4\% $$

Баланс сырья в прядильном производстве предполагает предварительную разработку баланса пряжи в ткачестве. Если предприятие является комбинатом, то баланс пряжи имеет внутрипроизводственное значение и служит для взаимной увязки различных технологических стадий изготовления конечной продукции. Если же речь идет о самостоятельной ткацкой фабрике, то баланс пряжи непосредственно примыкает к плану ее материально-технического обеспечения основным сырьем.

[^1]: В. Д. Шаталов. Методика планирования производства и управления хлопчатобумажной промышленностью. М., Профиздат, 1959, стр. 22.
