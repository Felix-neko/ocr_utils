# Запуск шага по паку-1

Порядок шагов, что каждый читает и пишет — в `docs/pack1_pipeline.md`; пути — в
`docs/data_layout.md`. Не запускать шаг, не проверив, что предыдущие пройдены (таблица там же).

## 1. Перед запуском

- Открыть скрипт, прочитать шапку: числа в опциях, `JOBS`, ожидаемое время. Если скрипт пишет в
  базу — убедиться, что он делает `source common.sh` (бэкап `$DB.bak`).
- Нет ли уже идущего прогона: `ps -eo pid,pgid,etimes,cmd | grep '[r]un_'`. Два прогона в один
  каталог портят выход и удваивают счёт за внешние модели.
- Свободное место на целевом томе (`df -h /mnt/SYSTEM ~/Projects`): очистка пака ~100 ГиБ,
  промежуточные PDF ~144 ГиБ.
- Если шаг требует GPU — `nvidia-smi`: видеопамять одна, чужой процесс на ней = OOM.
- Целевой путь начинается с `/mnt/SYSTEM` (заглавными) или `~/Projects/mts_markup`. В корень
  `/mnt/dump3` не писать.

## 2. Запуск

```bash
cd /home/felix/Projects/ocr_utils
LOG=~/Projects/mts_markup/logs/$(basename "$SCRIPT" .sh)_$(date +%Y%m%d_%H%M).log
mkdir -p "$(dirname "$LOG")"
setsid ./run_scripts/scan_markup/pack1/run_X.sh > "$LOG" 2>&1 < /dev/null &
PID=$!
echo "PID=$PID LOG=$LOG"
```

`setsid` обязателен: без него pgid ≠ pid и группу потом не снять. Сообщить пользователю PID и
путь к логу сразу.

## 3. Ожидание

Только по PID, никаких `pgrep -f`:

```bash
while kill -0 "$PID" 2>/dev/null; do sleep 30; done; tail -n 20 "$LOG"
```

Для длинных прогонов (часы) — не держать сессию в цикле: проверять `ps -p "$PID"` и хвост лога
по запросу пользователя. Прогресс смотреть в логе и по числу файлов в выходном каталоге.

## 4. Остановка

```bash
kill -- -"$PID"            # вся группа: скрипт, uv, python, forkserver, воркеры
sleep 2; ps -eo pid,pgid,cmd | grep '[f]orkserver'   # сирот быть не должно
```

Если сироты остались — снять их по PID (`kill <pid>`), детей раньше родителя.

## 5. После завершения

- Код выхода и последние строки лога; для пулов — нет ли `Traceback` в середине
  (`grep -n Traceback "$LOG"`).
- Выход лежит там, где ожидалось (`ls` целевого каталога, число файлов против числа полос).
- Если шаг пишет в базу — `sqlite3 "$DB" 'select count(*) from pages'` до и после сходится с
  ожиданием; `.bak` рядом.
- Сводку (время, число обработанных, число флагов) — в отчёт или в `docs/status.md`, если
  шаг закрывает направление.
