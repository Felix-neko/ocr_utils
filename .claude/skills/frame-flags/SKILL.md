# Флаги кадров: отсмотр папки выпуска и сайдкары

Схема и команды — `ocr_utils/frame_flags` (README там же). Флаги учитывает `scan_cropping.v2`:
`ignore-both` — кадр не обрабатывается вовсе; `ignore-left/right` — страница не идёт в `--output-pages`
и не тянет поле выпрямления; `no-splitting` — разворот пишется одним файлом `_LR`;
`no-illumination-left/right` — у страницы нет выравнивания освещения; `no-text-rectify-left/right` — страница не
выпрямляется по строкам (второе преобразование: поле по тексту; первое — Кунс по краям листа — остаётся);
`cover-left/right/both` — своя обложка (в `scan_markup` без обрезки краёв; освещение и выпрямление строк сам флаг
обложки не выключает — их ставят отдельно, см. таблицу). Прежнее имя `no-color-equalize-*` читается как
`no-illumination-*`.
`single-page` — в кадре одна страница: не резать, писать `<кадр>_P` (v2 и сам узнаёт такие кадры — `scan_cropping/v2/single_page.py`; флаг — когда автомат ошибся). `spread` — наоборот, кадр — разворот, автомат выключен. `single-page` нельзя сочетать с флагами одной стороны и `no-splitting`; обложка одной страницей — `single-page` + `cover-both`.

## Запись — только командой

Фото лежат под `/mnt/dump3/yandex_disk_linux_baby_zergling` (живая синхронизация). Туда разрешено
писать **только сайдкары и только** так:

```bash
uv run python -m ocr_utils.frame_flags write "<папка>/IMG_0005.jpg" --flag ignore-right \
    --note "библиотечная карточка закрывает правую страницу" --pair IMG_0006.jpg
```

Никаких `cp`/`>`/`tee`/`touch` в папку кадров (хук заблокирует), листы и CSV — только в scratchpad.
Существующий сайдкар без `--replace` не перезаписывается — это намеренно: сначала `show`, потом решение.
Удалить ошибочный — `remove <кадр>`. У обычного кадра сайдкара нет.

## Порядок работы по папке

1. **Обзор.** В scratchpad:
   ```bash
   uv run python -m ocr_utils.frame_flags sheets --input-dir "<папка>" --out-dir <scratch>/<выпуск>/sheets
   uv run python -m ocr_utils.frame_flags neighbors --input-dir "<папка>" --out <scratch>/<выпуск>/neighbors.csv
   uv run python -m ocr_utils.frame_flags show --input-dir "<папка>"     # уже размеченное
   ```
   Пересмотреть **все** листы (по 20 кадров, ~10 с на папку из 80 кадров). На листе под кадром — имя и
   уже стоящие флаги.
2. **Начало и конец папки — крупно** (`pair-sheet` первых 2–4 и последних 2 кадров или Read самого кадра,
   уменьшенного `convert -resize 1400x1400` в scratchpad). Тут живут обложки и форзацы (таблица ниже).
   Номер на обложке (месяц, № выпуска) сверять с именем папки: «02 оплачено» — февраль.
3. **Кандидаты в повтор** — строки `neighbors.csv`:
   - фон (стол, коврик, край подшивки) даёт `share` 0.01–0.05; повтор разворота — `share` от ~0.1;
   - повтор с поднятием страниц обычно: одна половина `share_left/right` ≥ 0.8, другая ≤ 0.25;
     карточка-вклейка, сдвинутая с одной страницы на другую, — так же (1974/01 0005/0006: 0.04 | 0.97);
   - пары берутся по порядку файлов, а не по номерам: дыры в нумерации (0613 → 0619) — норма;
   - **доля половины — только подсказка**: в 0619/0622 ХиП 1977/01 у левой 0.95, хотя в 0622 поднята
     именно левая. Решать глазами.
   По каждой паре-кандидату и по каждой паре соседних кадров с одним разворотом на листах (бывает и без
   высокой доли) — `pair-sheet A B --out <scratch>/…/pair_A_B.jpg --width 1000`.
4. **Какая страница поднята** — признаки из навыка `reshoot-review` §2 («Как отличить поднятую»):
   смотреть на **край листа**, а не на текст. Поднятая: лист выгнут и отходит от блока, под ним не видно
   стопки, строки дугой, часто наезжает на корешок или соседнюю страницу, палец у её внешнего края,
   колонтитул выше/ниже соседней. Плохо снятая (поднятая) страница кадра — та, что **игнорируется**.
5. **Записать**, затем `show` и отдать пользователю таблицу «кадр → флаги → почему». Сомнительное
   не помечать — отдельным списком «не уверен, посмотрите».

## Случай → флаги

| Случай | Флаги | Пример |
|---|---|---|
| Разворот снят дважды: в кадре A поднята правая, в B — левая | A: `ignore-right`, B: `ignore-left`, `--pair` друг на друга | ХиП 1977/01 IMG_0619 (`ignore-right`) / IMG_0622 (`ignore-left`) |
| Поднимали только в одном кадре, в другом обе плоские | поднятому — `ignore-<сторона>`, плоский без флага (или `ignore` той стороны, что в нём хуже) | — |
| Карточка-вклейка отклонена в разные стороны | в каждом кадре `ignore-` той страницы, которую карточка закрывает | ПХ 1974/01 IMG_0005 (`ignore-right`), IMG_0006 (`ignore-left`) |
| Обложка подшивки (не журнала), одиночный кадр | `ignore-both` | ХиП 1977/01 IMG_0580; ПХ 1974/01 IMG_0001 |
| Пустой форзац подшивки целиком (обе страницы — форзац / карточка учёта) | `ignore-both` | ХиП 1977/01 IMG_0581, ПХ 1974/01 IMG_0002 |
| Форзац слева, обложка журнала справа | `ignore-left` | ПХ 1974/01 IMG_0003 |
| В конце папки: слева задняя обложка номера, справа передняя обложка **следующего** | `ignore-right` | ПХ 1974/01 IMG_0087 |
| В начале папки: слева задняя обложка **предыдущего** номера, справа передняя обложка нашего | `ignore-left` | ПХ 1974/02 IMG_0001 |
| Сквозная таблица, схема, заголовок или текст через корешок | `no-splitting` | — |
| Выравнивание освещения портит страницу (цветная печать, плашки, фото на полосу), а автоматика v2 её не узнала (она пропускает целиком цветные: FULL, ≥ 20 % насыщенных или тонированный фон ≥ 0.3) | `no-illumination-<сторона>` | — |
| Своя **передняя** обложка номера (крупное название, плашки, мало строк) | `cover-<сторона>` + `no-illumination-<сторона>` + `no-text-rectify-<сторона>`; чужая сторона — `ignore-<сторона>` | ПХ 1974/01 IMG_0003: `ignore-left` + `cover-right` + `no-illumination-right` + `no-text-rectify-right` |
| Своя **задняя** обложка с анонсом книг, оглавлением, выходными данными — текст занимает бо́льшую часть страницы | только `cover-<сторона>`: **без** `no-text-rectify` (строки надо выпрямлять) и без `no-illumination`, если обложка белая; чужая сторона — `ignore-<сторона>` | ПХ 1974/01 IMG_0087: `ignore-right` + `cover-left` |
| Задняя обложка без текста или почти без него (цветная картинка, реклама на всю полосу) | как передняя: `cover-` + `no-illumination-` + `no-text-rectify-<сторона>` | — |
| Страница внутри номера, которую целиком занимает цветная картинка (вклейка-иллюстрация, фото на полосу, карта) | `no-text-rectify-<сторона>` (+ `no-illumination-<сторона>`, если цветная) | — |
| Обычный разворот | сайдкара нет | — |

Задняя обложка своего номера — **не** игнорируется (она часть выпуска), игнорируется только чужая. Своя обложка
помечается `cover-<сторона>`: `scan_markup` не обрезает её края. Освещение и выпрямление по строкам решаются
отдельными флагами: передней обложке и странице-картинке — `no-illumination-` и `no-text-rectify-<сторона>`
(поле по паре строк крупного названия гнёт картинку), задней обложке с анонсом книг выпрямление строк **нужно**
(иначе строки списка остаются наклонными — ПХ 1974/01 IMG_0087_L) — `no-text-rectify` ей не ставить.
Отличать «своя/чужая» по номеру и месяцу на обложке и по положению кадра в папке.

Противоречия схема не пропустит: `no-splitting` вместе с `ignore-left/right` — ошибка;
`ignore-left` + `ignore-right` сами сводятся к `ignore-both`; неизвестный флаг — ошибка.
