# Тесты

- Структура зеркалит пакет: `tests/ocr_utils/<подпакет>/test_<модуль>.py`, `tests/research/...`.
- Данные — синтетика, генерируемая в тесте или в `conftest.py`/`synthetic.py`/`pages.py`
  подпакета. Реальные сканы с `/mnt/dump3` и `/mnt/SYSTEM` в тестах не читать: их нет на
  другой машине и они медленные. Исключение — маленькие кадры уже в репо
  (`tests/ПХ_1931_02_03_кадры_с_просвечивающей_бумагой`).
- GPU-модели в тестах не грузить; слой с моделью подменять заглушкой (образец —
  тесты `scan_cropping`, где `GpuModels` мокается).
- Запуск одного подпакета: `uv run pytest tests/ocr_utils/<подпакет> -q`. Полный прогон долгий —
  запускать по подпакету, который меняли.
- `ocr_utils/legacy` тестами не покрыт намеренно; для него тесты не писать.
