# research/colour_pages — цветные страницы и фон

Стенд для `scan_cropping/v2`. Сам пакет он не меняет: шаги пайплайна подменяются по кэшу прогона v2 (`--cache`), в
кэш ничего не пишется.

**Правила перенесены в пакет** (2026-10-15, `1657057`, решение пользователя): `scan_cropping/v2/colour_pages.py`
(`--colour-pages`), правило фона — в `background.bg_dark` (`MAT_OTSU_MIN_GAP`). `classify.py` и `palette.py` стенда —
реэкспорт из пакета, `background.py` стенда пересчитывает книгу правилом пакета. Первый прогон пака-6 с ними —
`/mnt/hotstore/scan_processing/scan_cropping_v2/pack6_v5`.

| Модуль | Что |
|---|---|
| `classify.py` | (реэкспорт из пакета) уровень цветности страницы: целиком цветная (медиана хромы ≥ 20), цветные элементы, следы цвета, обычная |
| `palette.py` | (реэкспорт из пакета) палитра уверенного центра страницы (80 % трапеции) и рост бумаги у края по ней — только вверх и вниз, с преградой «тень кромки листа» |
| `segment.py` | шаг «бумага и страницы», как `pipeline.cpu_pages`, с правилами для цветных страниц (`Rule`: рост по палитре, защита контента при любой позе) и мера «контент за бумагой» (блоки surya вне бумаги) |
| `background.py` | фон на коврике у кадра без печати: пересчёт маски книги по кэшу правилом пакета и сравнение с кэшем (МТС 1990/04 IMG_1108) |
| `cli.py` | `background`, `segment` |
| `sets/` | развороты из первых и последних 6 каждого выпуска пака-6 по уровням цветности: `colour_full` (77), `colour_partial` (19), `colour_trace` (23), `control` (20) |

## Запуск

```bash
uv run python -m research.colour_pages background --out-dir /mnt/hotstore/scan_processing/scan_cropping_v2/colour_pages/background
uv run python -m research.colour_pages segment --out-dir /mnt/hotstore/scan_processing/scan_cropping_v2/colour_pages/segment
```

## Итоги (2026-10-15, кэш `pack6_v4_shadow`)

**Фон на коврике без печати.** Из 2480 кадров маска книги изменилась у 6. Это кадры без печати, у которых утечка к
рамке кадра пропала:
- МТС 1990/04 IMG_1108;
- МТС 1990/07 IMG_0056;
- МТС 1990/10 IMG_0440;
- РИСК 1991/02 IMG_0823;
- РИСК 1991/03 IMG_0201;
- РИСК 1993/03 IMG_0377.

У остальных маска совпала с кэшем до пикселя.

**Цветные страницы** (подсказка пользователя: важнее не потерять контент на краях, чем не захватить периферию;
палитру краски и бумаги видно по уверенному центру, незнакомый цвет на краю — обложка или фон).
- **Контент.** Напечатанного контента (блоки surya) за бумагой у цветных страниц почти нет уже в пакете: 14 мм² на весь
  набор, один кадр (РИСК 1993/02 IMG_0164); с правилами — 0. Защита контента его и так держит.
- **Поля и рваные края.** Теряются именно они, и их добирает рост по палитре: 17.6 тыс. мм² на 74 из 77 кадров
  (медиана 155 мм², наибольшее 1090). МТС 1990/04 IMG_1113 становится «плоской» — это единственная смена позы.
- **Только вверх и вниз.** Вбок по палитре расти нельзя: за боковыми сторонами белый торец книжного блока, белое есть и
  в палитре страницы, а тени кромки у торца нет (МТС 1990/09 IMG_0310, РИСК 1991/02 IMG_0642). Боковые стороны берёт
  `side_fit.snap_sheet_edges`.
- **Остальные уровни.** У цветных элементов, следов цвета и контроля ничего не меняется.

**Отвергнуто:**
- мера «насыщенное за бумагой» — на цветных кадрах это переплёт (красная ткань крышки МТС 1991/01 IMG_0527);
- краска `book.ink` в мере контента — она ловит тень кромки и пятна у пальца;
- Савола по кольцу опоры тени (стенд `finger_repaint`) — нейтральна.
