# research/edge_cut_pages — строки, срезанные краем листа

Стенд ищет на фото-разворотах подшивок кадры, где своя печать страницы (строки, колонтитулы, номера, таблицы)
уходит за кромку листа: лист загибается, и часть строки скрывается за его краем. Обложки не считаются, пальцы —
тоже (печать под пальцем срезом не считается). Только CPU, без моделей.

Первый прогон — пак-6 МТС/РИСК 1989–1993 «от Лены» (2 416 кадров JPG 5687×4268, 29 выпусков).
Run-скрипт: `run_scripts/edge_cut_pages/run_pack6.sh`. Выход: `/mnt/hotstore/scan_processing/edge_cut_pages/pack6/`.

## Метод (`detect.py`)

Всё — на ½ кадра (`cv2.IMREAD_REDUCED_COLOR_2`, ~6.9 px/мм на развороте).

1. **Тёмное**: адаптивный порог (окно 51, сдвиг 15) ∪ очень тёмное (< 0.4·p95).
2. **Структуры**: толстое — раскрытие квадратом 9 (коврик, крышка, заливки); тонкое — тёмный пробег ≥ 61 px
   по одной из осей 0°/90°/±45° **вне толстого** (линейки, тени). Буква, упёршаяся в коврик, остаётся глифом:
   пробег «буква + коврик» тонким не считается.
3. **Край листа**:
   - граница толстых структур, **задевающих рамку кадра** (коврик, крышка); логотипы, плашки и иллюстрации
     внутри страницы — не край;
   - ступенька «бумаги без печати» (закрытие серого кругом 25, морфологический градиент ≥ 40), кроме ступенек
     в 7 px от толстого внутри страницы;
   - только для концов строк — тонкие вертикальные тёмные линии ≥ 61 px. Край верхнего листа над корешком
     (IMG_0542) виден как узкая полоса тени (~20 px) с тёмной линией: крупное закрытие её заливает.
   - Без зоны пальцев (кожа YCrCb, Cr ≥ 146, раздутие 41 px) и полосы 20 px у рамки кадра (срез рамкой снимка —
     не край листа).
4. **Глифы**: тёмное вне структур, высота 5–60, ширина ≤ 90, площадь ≥ 12. **Строки**: смыкание глифов вдоль
   на 25 px, разрыв на краю листа (строки двух страниц у корешка не сливаются).
5. **Касание**: глиф в 2 px от края; сторона касания — по ходу края в окрестности глифа (горизонтальный край —
   снизу/сверху, вертикальный — слева/справа).
6. **Вердикт строки** (≥ 3 глифов, длина ≥ 2 высот и ≥ 30 px, на белой бумаге листа: маска листа без синевы
   крышки, фон строки ≥ 0.72·p95, краска нейтральная):
   - **низ / верх**: касаются краем вдоль ≥ 3 глифов и ≥ 25 % строки, и под ними (4–40 px за краем) «снаружи»
     (коврик, крышка) ≥ 50 % — серые плашки и растр иллюстраций не проходят;
   - **конец строки**: крайний глиф (≥ 0.5 медианной высоты, строка не выше 2.5 высот глифа) касается края по
     ходу строки; **наружный край**, если в полосе 6 см за краем «снаружи» ≥ 30 %, иначе **корешок**.
7. **Обложка**: доля цветного (хрома > 30) среди не тёмного кадра ≥ 0.12 — голубые обложки МТС и РИСК
   (на паке-6: 80 кадров).

Мера кадра `score` — сумма касающихся глифов по строкам «низ/верх/наружный край».

## Отбор (`cli.py select`)

Кадр в `links/`, если не обложка и одно из:
- есть строка «низ»/«верх» и `score` ≥ 3;
- строк «наружный край» ≥ 2 (одиночное касание наружного края — чаще крап обреза или пятно у кромки);
- строк «корешок» ≥ 8.

Пороги — по распределению пака и отсмотру листов по поясам (`sheets/frames_score_*.jpg` — лучшая строка
кадра по поясам меры, `sheets/<сторона>_<пояс>.jpg` — строки по поясам числа глифов у края):

| пояс | что видно |
|---|---|
| низ/верх, `score` ≥ 3 | почти всё — настоящие срезы нижней строки и колонтитула («4 МТС № 11») у загнутого низа |
| наружный край ≥ 2 строк | в основном настоящие (пак-7-кадры МТС 1991/04: строки уходят за край соседнего листа); сторона часто перепутана с корешком |
| наружный край 1 строка | шум: крап обреза, полосы стопки, логотипы — не отбирается |
| корешок ≥ 8 строк | ~8–9 из 10 — настоящие обрубленные начала строк под краем левой страницы |
| корешок 3–7 строк | ~половина настоящие → `links_by_side/spine_maybe` |
| корешок 1–2 | одиночные касания у корешка, ненадёжно — не отбирается |

Распределение строк у корешка по кадрам (не обложки, 2 336): 0 — 1 343, 1 — 364, 2 — 163, 3–4 — 181, 5–7 — 127,
8–10 — 59, 11–15 — 67, > 15 — 32.

## Итог по паку-6

Отобрано **201** кадр из 2 416 (обложек 80): низ — 20, наружный край — 27, корешок ≥ 8 — 158 (из них 154 — только
корешок). По журналам: МТС 1990 — 40, МТС 1991 — 42, РИСК 1991 — 113 (из них 1991/02 — 60, почти все у корешка;
1991/05 — 36), РИСК 1993 — 6, РИСК 1992 — 0. «Возможно у корешка» (3–7 строк) — ещё 302.

Точность по отсмотру листов (оценка глазами, не разметка): низ/верх ~90 %, наружный край ≥ 2 ~80 % (по факту
среза; сторона — хуже), корешок ≥ 8 ~85 %.

## Известные провалы

- **Сторона «наружный край» / «корешок»** решается по тому, что за краем (коврик/крышка — наружу, иначе — корешок);
  на кадрах, снятых по странице, где соседняя страница с жирной печатью лежит за краем, или стопка обреза широкая,
  сторона путается.
- **Край листа над стопкой листов той же бумаги** (без тени и без коврика за ним) не виден: срез низа строки над
  обрезом стопки не ловится — только над ковриком/крышкой.
- **Корешок**: если край верхнего листа над корешком не даёт ни ступеньки ≥ 40, ни тёмной линии, срезанные
  начала строк не находятся (IMG_0638, IMG_0636); на «ровных» глубоких корешках одиночные касания — шум.
- **Логотипы и крупные буквы** у края (голубой «Маркетинг», «МЕРА») изредка проходят как срез конца строки.
- Обложка — по доле цветного: белый форзац или титул без цвета обложкой не считается (на них обычно нечего срезать).

## Команды

```bash
uv run python -m research.edge_cut_pages run --root <пак> --out <выход> --jobs 12 [--only РИСК/1991/05]
uv run python -m research.edge_cut_pages select --out <выход> --min-score 3 --min-outer 2 --min-spine 8
uv run python -m research.edge_cut_pages sheets --out <выход>
```

Выход: `scores.csv` (все кадры: число строк по сторонам, мера, доля цветного, обложка), `lines.jsonl`
(срезанные строки: сторона, рамка на ½ кадра, глифов, касающихся), `overlays/` (кадры со срезом не у корешка или
≥ 2 строк у корешка: край листа, глифы у края, рамки строк по стороне, увеличенные вырезки, легенда в поле),
`crops/`, `sheets/`, `cut_pages.csv`, `links/<журнал>/<год>/<выпуск>/`, `links_by_side/{bottom,top,outer,spine,spine_maybe}/`.

Время: ~6–10 мин на пак при 12 воркерах (5–8 кадр/с, упор в чтение NTFS).
