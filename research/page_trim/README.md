# research/page_trim — зона обрезки выпрямленных страниц

У краёв страниц `scan_cropping.v2 --output-pages` остаётся мусор:
- тень и кромка стопки листов;
- край соседней страницы за кривой линией разреза;
- метки у корешка (ПХ 1974/01 IMG_0078_R — повёрнутая «49» в 1–2.5 мм от разреза);
- серый закрас у края.

Фиксированные отступы опасны: линия разреза «плавает» и может съесть контент. Стенд сравнивает способы осевой рамки
«зона контента». В `scan_markup` эта рамка уходит в CVAT как «Зона обрезки».

## Вход

- Страницы `--output-pages`.
- Паспорта `--output-pages-meta` (`ocr_utils/scan_cropping/v2/rectify/passport.py`): часть `L` / `R` / `LR` задаёт сторону
  разреза, флаг `cover-*` означает обложку — у неё рамка во всю страницу. Из паспорта же берутся dpi и контуры закраса
  пальцев для листа.

## Контент страницы (`content.py`)

- Строки и блоки — `text_field.analyze_page` выпрямления, движок по краске, CPU.
- Растр, таблицы и line art — `text_field.page_regions` (`page_layout` по пикселям).
- Краска — на копии 150 dpi: темнее медианного фона в окне 15 мм.
- **Сор** — короткая строка (до 12 мм), лежащая по горизонтали вне тела страницы дальше 2 мм. Тело — длинные строки,
  блоки и области. Поэтому номер страницы под колонкой и в колонтитуле — контент, а метка у корешка — сор.

## Способы (`methods.py`)

| Способ | Рамка |
|---|---|
| `A_fixed` | страница минус отступы: верх, низ, внешний край, край у разреза (мм) |
| `B_content` | охват контента без сора плюс запас 2 мм |
| `C_ink` | охват компонент краски: без касающихся края и без мелких пятен у краёв вдали от контента; плюс запас |
| `D_hybrid` | рамка A, раздвинутая по стороне до контента B, если он заходит за отступ |

## Меры

- `lost_items`, `lost_mm2` — контент без сора вне рамки; должно быть 0.
- `junk_mm2` — краска в полосе 8 мм у краёв внутри рамки, вне контента.
- `strays_in` — сор внутри рамки.
- `cut_*_mm` — сколько срезано по сторонам.

Для калибровки отступов A по паку:
- `content_*_mm` — расстояние от контента до края по сторонам (верх, низ, внешний край, разрез);
- `junk_*_mm` — глубина мусора, касающегося края.

Отступ стороны должен быть больше верхнего перцентиля мусора и меньше нижнего перцентиля расстояния до контента.

Листы `sheets/<страница>.jpg`:
- рамки способов без заливки;
- сор — красная рамка;
- закрас пальцев — малиновый контур;
- меры — в шапке, легенда — в поле.

## Запуск

```bash
uv run python -m research.page_trim run --pages <страницы> --meta <паспорта> --out <выход> [--sample N] [--jobs 12] \
    [--top-mm 4 --bottom-mm 4 --outer-mm 3 --cut-mm 5 --margin-mm 2]
```

Тесты: `uv run pytest tests/research/page_trim -q`.
