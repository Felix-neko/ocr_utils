# research/gutter_strip — полоса-вклейка у корешка

Стенд по кэшу прогонов `scan_cropping.v2` (CPU; уточнение ленты `refine` — GPU). На разворотах подшивок ПХ у корешка бывает наклеена полоса:
бумажная проклейка у стыка тетрадей или у форзаца (белее страниц, две тонкие складки по кромкам, часто сгиб
посередине) и тканевая лента-марля у обложки. SAM 3 белую полосу не берёт (щель), полосу с тенью рвёт языками;
склейка v2 добирает куски, рамка страницы у корешка идёт «лестницей», а неплотно приклеенная полоса даёт всплески
верха и низа страницы у корешка.

Что делает стенд:

1. **Обнаружение** — шесть способов по ленте ±25 мм вокруг корешка `auto`, выпрямленной вдоль него
   (`band.py`, `detect.py`): A — щель и рваность экземпляров SAM 3; B — светлое плато тона; C — пара прямых
   ступеней яркости; D — смена бумаги у сгиба (`page_cutting.fold.page_spine_edge`); E — ширина без текста;
   F — пара тонких складок.
2. **Сегментация** (боевая, `ocr_utils/scan_cropping/v2/gutter_strip.py` `segment_strip`) — края полосы по строкам в
   ±4 мм от кромок щели SAM 3 (ступень или складка), прямые Хубера по ним — **вспомогательные линии**, маска полосы
   между ними в книге.
3. **Линия корешка** (`gutter_strip.spine_line`) — наклон = средний наклон двух краёв полосы, если они согласны (иначе
   наклон разделителя v2), сдвиг — середина полосы; без полосы — разделитель v2 как есть.
4. **Подгоночные области** (`fit.py`) — `scan_cropping.v2.page_frames.spread_frames`: верх и низ по маске до
   вспомогательной линии (6 мм перед ней точки негодны), дальше касательной до линии корешка; «было» —
   `page_boundary.fit_boundary` сплайном по маске до корешка.
5. **Уточнение ленты у корешка** (`refine.py`, `refine_overlay.py`, `refine_fit.py`; GPU) — см. раздел ниже.

## Запуск

```bash
run_scripts/scan_cropping/run_gutter_strip.sh     # features → evaluate → run
run_scripts/scan_cropping/run_gutter_strip_refine.sh   # refine по sets/refine_ph1975.txt и sets/refine_hp1991.txt
uv run python -m research.gutter_strip rechoose --cache … --src-root … --set … --refine-dir … --out …   # пороги без GPU
uv run python -m research.gutter_strip refine-fit --cache … --set … --refine-dir … --out …   # рамки «v2 | A»
uv run python -m research.gutter_strip region-fit --cache … --set … --refine-dir … --out …   # полоса-область «v2 | R»
uv run python -m research.gutter_strip sheets --cache … --features-csv … --out … [--keys файл] [--skip-labeled …]
```

Выход: `/mnt/hotstore/scan_processing/gutter_strip/ph1975/` — `features.csv`, листы `sheets_*`, `run/run.csv`,
оверлеи `run/strip/`, `run/none/`.

## Уточнение ленты у корешка (2026-10-23)

Задача пользователя: при полосе SAM 3 либо рвёт одну из страниц языками на полосу (ПХ 1975/04 IMG_0066, 0068, 0082),
либо оставляет большую щель (0067), либо и то и другое (0083); языки сращены со страницей, щель меряется до их
кончиков — 0082 не найдена (7.7 мм), у 0083 края легли не туда, а без полосы сплайн верха ныряет за скруглённый угол
маски (0082: ~7–10 мм).

**Как устроено** (`refine.py`, по образцу `scan_cropping/v2/edge_refine.py`):

- Лента ±25 мм вдоль разделителя v2 в полном разрешении (исходный кадр; `SpineBand`: строка — строка кадра,
  столбец — горизонтальный сдвиг), плюс 12 мм за верх и низ пролёта страниц. Куски 50 мм × сжатие, как у дальней
  стороны.
- Способы, каждый даёт по строкам правый край левой страницы и левый край правой. Сокращённый набор: SAM 2.1 точками
  страниц (свои положительные на ±15 мм, чужая страница и середина щели — отрицательные) ×4 и ×4 lvL; SAM 3
  «book page» ×4 (экземпляры по столбцам ±15 мм; один на обе — промах); без сети — пара прямых ступеней (`detect_edges`)
  и `solid` — сплошная кромка экземпляра грубого SAM 3 (40 % строк, ближних к своей странице), прямая RANSAC и поиск
  наклонной линии на снимке (±1.5°, окно −2.5…+6 мм к странице). Полный набор — плюс SAM 2 полосой как классом,
  ×1, CLAHE, SAM 3 lvL, SAM 3 «paper strip», пара складок.
- Приёмка края: покрытие ≥ 0.9; прямая RANSAC (допуск 1 мм), на ней ≥ 60 % строк — остальные выбросы (кусок на
  кончиках языков); по средней части пролёта: рваность p90 ≤ 0.3 мм, ступень ≤ 1 мм, остаток к прямой ≤ 0.8 мм; краска
  своей страницы за краем дальше 2.5 мм ≤ 10 мм²; края не заходят друг за друга. Опора — отклик линии вдоль края
  (ступень светлоты без букв или складка по среднему вдоль корешка: пунктирная кромка листа).
- Выбор края: согласие сетей (медиана, ±2 мм, наименьшая рваность, ближний к своей странице); его вытесняет принятый
  край ближе к странице дальше 2 мм с опорой ≥ 10 и краской ≤ 5 мм² (кромка листа за белой полосой, которую сети
  считают той же бумагой: 0083 — +16.3 мм вместо сгиба +3.3); без принятых сетей — край с сильнейшей опорой.
- Полоса есть, если медиана ширины между краями ≥ 5 мм. В `Strip` — прямые Хубера по краям средней части пролёта.

**Множества**: `sets/refine_ph1975.txt` — 107 кадров (41 полоса, 33 спорных и неразмеченных подозрительных,
33 без полосы); подозрительная лента — щель грубого SAM 3 ≥ 4 мм или языки кромки ≥ 10 % строк
(`detect_sam3.extra` `tongue_*`): 111 из 1024 кадров года, 40 из 41 полосы. `sets/refine_hp1991.txt` — 27 кадров ХиП

## Полоса как область (2026-10-23, вводные пользователя)

Полоса может менять ширину по высоте и идти только по части линии разреза; кромки — любые гладкие кривые; маски
страниц могут обтекать конец полосы; уточнённые края — вернуть в сегментацию страниц.

- **Края без прямых** (`refine.py`): край способа режется на гладкие куски (`edge_pieces`: скачок > 1.5 мм — разность
  медиан окна 3 мм до и после строки — или пропуск > 3 мм; кусок ≥ 20 мм), объезды выбрасываются (`drop_detours`:
  кусок, оба соседа которого ближе к своей странице на > 2 мм и сходятся между собой, — кусок способа на кончиках
  языков, 0082). Приёмка — доля строк в кусках ≥ 0.6, рваность внутри кусков ≤ 0.3 мм, краска; прямизна и скачок
  между кусками не проверяются (со скачка начинается полоса на части длины). Пропуски и концы — интерполяцией.
- **Область** (`refine_region.py`, `build_region`): строки, где между краями ≥ 3 мм, закрытие разрывов 10 мм, серии ≥
  30 мм с медианой ширины ≥ 5 мм; маска — между краями по строкам.
- **Торцы** (`shape_ends`): в 15 мм от конца серии и за ним в столбцах полосы область — светлая бумага (Оцу по
  месту), связанная с телом полосы: торец идёт по реальной бумаге полосы, а не срезом по строкам страниц (10/IMG_0083).
  Края по сторонам — по строкам уточнённых краёв, без прямых: область неправильной формы.
- **Продолжение полосы** (`extend_along_spine`, по просьбе пользователя 2026-10-23): от концов полосы — на 20 мм вдоль
  линии корешка, ширина — по 5 мм у конца; страница для подгонки — без полосы и продолжения, наибольшая связная часть
  (`fit_masks`: отрезаны тонкие мостики масок SAM над концом полосы, 12/IMG_0066). Через полосу и продолжение — своя
  экстраполяция кривой каждой страницы параболой по последним 30 мм до линии корешка (`extrapolate`: наклон ≤ 0.15,
  вклад кривизны ≤ 1 мм) вместо моста между углами.
- **Обтекание** (`snap_ends`): конец серии ближе 8 мм к верху (низу) страниц у полосы, а в зазоре над ним в столбцах
  полосы — бумага в ≥ 60 % столбцов: полоса доводится до края листа; конец ближе 10 мм — верх (низ) подгоняется как с
  полосой.
- **Страницы** (`correct_pages`): в карте экземпляров SAM 3 у корешка (±25 мм) метка страницы за её уточнённым краем
  снимается, бумага до края — её метка, полоса — без метки; страницы — `page_pose.page_quads` по бумаге без полосы,
  разделитель — `spine_candidates` по ним. Линия корешка (`region_spine`): полоса почти во всю высоту (строк без неё
  < 30 % пролёта) — середина области; полоса на части длины — прямая Хубера по стыку страниц в строках без полосы и по
  тому краю полосы, что продолжает стык (середина расширяющейся в одну сторону полосы уводила корешок в страницу:
  10/IMG_0081, у верха на 3.6 мм).
- **Подгоночные области** (`region_frames`, правка 2026-10-23 по 04/IMG_0082): защита у полосы 1.5 мм (было 6 —
  выбрасывала изгиб низа левой страницы: 2 мм в последних 6–8 мм у полосы); зона сплайна у корешка всегда — страница
  исправлена по краю полосы, зона отсчитывается от него; выемки края закрываются горизонтальным закрытием 15 мм, кроме
  стороны полосы; точки глубже 3 мм от жёсткой кривой (без зоны) у полосы негодны, а если гибкая кривая у края полосы
  ушла от жёсткой дальше 3 мм — берётся жёсткая (выемка от клочка обложки у края полосы, 12/IMG_0084) — заменено
  отсевом по форме (`strip_side_rejects`): отвесные точки (перепад круче 1:1 — срезанный угол у полосы) и выемки
  (наибольшая глубина не у полосы, у полосы мельче на 1.5 мм) негодны, монотонный загиб к полосе остаётся (04/IMG_0066); через полосу —
  отрезок между концами двух страниц у её краёв, угол — его точка на линии корешка (касательная и хорда своей страницы
  давали взлёт угла на 12 мм и V на корешке). Прежняя подгонка — `region-fit --legacy-guard`
  (`…/refine/*_region_g6`). ХиП: ни один угол не сдвинулся; ПХ: углы у 40 кадров сдвинулись > 1 мм — лист отсмотра
  глазами: изгиб у полосы повторяется, мост ровный; хуже — 02/IMG_0085 (верх левой страницы взят жёстким, на ~1 мм выше
  края у полосы).
- Команда `region-fit` (CPU) → `region.csv`, оверлеи `regions/{changed,strip,none}/`: «было» (страницы и полоса v2) |
  «стало» (левая страница — синяя, полоса — оранжевая, правая — зелёная; линия корешка, рамки страниц), справа — верх и
  низ у корешка ×3.

Итог (`/mnt/hotstore/scan_processing/gutter_strip/refine/{ph1975,hp1991}_region`): ПХ — 39 из 41 полосы, ложные — 2
из 33 (01/IMG_0022 и 10/IMG_0081 — метки Claude, на отсмотр); ХиП — 0 ложных, рамки на загибах не меняются (угол
сдвинулся > 1 мм только у сломанной синей обложки 11/IMG_0317). Полоса на части длины — 10/IMG_0066 (нижние 161 мм,

## SAM 3 по растянутой светлоте у краёв страниц (2026-10-23)

`levels-top` (и `--bottom`) — что добавил бы второй проход SAM 3 по кадру с растянутой светлотой (`sam3.npz`
`raw_lv`, опция v2 `--dual-levels`) к основному (`raw` ∪ `raw_noink`) в зоне краёв страниц: от крайней строки страниц
v2 на 10 мм наружу и 15 мм внутрь; оверлеи по поясам добавки (`/mnt/hotstore/scan_processing/gutter_strip/
levels_top`, `levels_bottom`).

На фон объединение не выводит; заделывает выемки края (10/IMG_0007 — ямы у верха левой страницы у корешка) и дыры
внутри страниц. Растянутый проход сам по себе теряет больше (основной видит, растянутый нет: медиана 30–93 мм²) —
поэтому объединение, не замена. По решению пользователя объединение у **верхних** краёв включено в `region-fit`
