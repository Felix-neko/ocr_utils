# research/single_page — «в кадре одна страница»

Стенд по кэшам прогонов `scan_cropping.v2` (только CPU, кэши только читаются). В кадре бывает не раскрытый разворот, а
одна страница: крышка подшивки, обложка журнала, снятая отдельно, страница «фото по страницам» с полоской соседней. v2
всё равно строит две страницы — например, ПХ 1975/10 IMG_0085 (задняя крышка с мраморной бумагой и штрихкодом): SAM 3
дал один экземпляр, запасной разрез `glue.split_pages` по провалу печати поставил «корешок» у кожи переплёта, и
выход страниц записал `IMG_0085_L` на весь лист и `IMG_0085_R` — полоску 15 мм.

Отчёт с распределениями, порогами и планом встраивания — `reports/single_page.md`.

## Признаки (`features.py`)

По кадру из `pages.json`, `sam3.npz` (`inst`), `book_veto.npz`/`book.npz`, `paper.npz` (масштаб сегментации,
6.9 px/мм):

* `n_pages`, `n_inst` — страниц v2 и экземпляров-страниц SAM 3; `source` — откуда две страницы (`instances` —
  экземпляры SAM 3, `print` — один экземпляр, разрез по провалу печати, `single` — страница одна);
* `paper_w_mm`, `paper_h_mm`, `paper_aspect` — осевая рамка итоговой бумаги;
* `w_left_mm`, `w_right_mm`, `width_ratio`, `overlap_mm`, `narrow_keystone`, `narrow_pose` — трапеции страниц;
* `print_spine` — печать на линии разреза относительно страницы (оболочки печати выпуклые и у корешка почти не
  проваливаются: признак не разделяет, оставлен для отчёта);
* `typical_w_mm`, `wide_rel`, `narrow_rel` — ширины относительно типичной страницы набора (медиана ровных разворотов).

## Правило (`rule.py`)

| Вердикт | Условие | Что делать |
|---|---|---|
| `no_page` | бумаги нет или рамка бумаги ниже 130 мм | страниц нет (закрытая крышка, бумага — ярлык) |
| `single` | одна трапеция; или две, узкая уже 0.5 широкой, рамка бумаги уже 0.78 высоты, экземпляр SAM 3 один | одна страница без разреза |
| `sliver` | то же, но экземпляров SAM 3 два (настоящий корешок, у края — полоска соседней) | писать только широкую |
| `spread` | иначе | разворот |

## Запуск

```bash
run_scripts/scan_cropping/run_single_page.sh      # features → evaluate → листы по поясам
uv run python -m research.single_page features --cache имя=кэш_v2 [--cache …] --out … --jobs 12
uv run python -m research.single_page sheets --out … --name пояс --where "verdict=='single'" [--sort key] [--issue-edges 2]
uv run python -m research.single_page evaluate --out … --labels research/single_page/sets/labels.txt
```

Выход: `/mnt/hotstore/scan_processing/single_page/` — `features.csv` (с вердиктом), `thumbs/<набор>/<ключ>.jpg`
(миниатюры `seg.png` с трапециями: левая синяя, правая красная), `sheets/<пояс>_NN.jpg` и `sheets/<пояс>.txt` (ключи),
`evaluate.txt`.

## Разметка

`sets/labels.txt` — строка `набор/ключ_кадра # single|sliver|no_page|spread|maybe — заметка`. Перечислены все
неразвороты пяти наборов (отсмотр поясов `a_print`, `b_le1page`, `c_inst_narrow`, `e_edges` — первые и последние два
кадра каждого выпуска) и пограничные развороты; неперечисленный кадр считается разворотом.
