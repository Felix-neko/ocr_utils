# research/page_rectify — выпрямление страниц по подгоночным областям

Стенд по итогам прогона `scan_cropping.v2` (только CPU, боевой код не меняется). Подгоночная область страницы
(`scan_cropping/v2/page_frames.spread_frames`) — криволинейная трапеция: верх, низ и внешняя сторона — сплайны с
узлами на изгибах, сторона у корешка — отрезок линии корешка. Стенд переводит итоговый кадр так, чтобы область каждой
страницы стала прямоугольником.

## Как устроено

- **Области** (`frames.py`) в кэше v2 не хранятся (их рисует только оверлей `07_lines`), поэтому они пересчитываются
  по кэшу кадра тем же кодом, что в `pipeline.finish_frame`. Рамка вырезки — `paper_bbox(бумага ∪ защита)`. Если её
  размер не совпал с итоговым TIFF (кэш перезаписан другим прогоном), кадр получает статус `cache_mismatch` и
  копируется как есть.
- **Карта** (`coons.py`) — поверхность Кунса по четырём сторонам, каждая параметризована долей длины дуги:
  `P(u,v) = (1−v)·T(u) + v·B(u) + (1−u)·L(v) + u·R(v) − билинейная по углам`. Это не аффинное преобразование
  (аффинное кривые не выпрямляет), но на прямоугольной области оно сводится к тождеству. За пределами области стороны
  продолжаются касательной (`TANGENT_MM` = 5 мм у конца), и карта линейно уходит на поля.
- **Расклад** (`plan_layout`): ширина прямоугольника — средняя длина верха и низа, высота — длина стороны у корешка.
  Прямоугольники стоят встык по линии корешка, верх каждого — на высоте его угла у корешка. Так точки корешка с обеих
  сторон ложатся на одну высоту и шва нет; высоты левой и правой страницы могут различаться. Поля холста — расстояния
  от областей до краёв итога v2.
- **Выборка**: `cv2.remap`, бикубически, за краем итога — отражение. Тег dpi берётся из итога v2.
- Кадр без двух страниц (`no_frames`), без бумаги (`no_paper`) или с ошибкой копируется как есть.

## Второе преобразование по тексту (`text-run`)

Кунс выпрямляет страницу по краю листа, а изгиб строк внутри страницы ему не виден: у ХиП 1991 строки оставались
волнистыми, отбивки колонок — наклонными. Поэтому есть второй проход.

1. **Освещение** (`illumination.py`) — перенос Equalize illumination из ScanTailor Advanced (исходники —
   `/home/felix/Projects/scantailor-advanced`, разбор — `reports/scantailor_equalize_illumination_color.md`).
   Копия 300 px, предобработка двумя способами с выбором по полиному 3×3, маска фона, полином 8×5, затем
   `Y' = 255 при Y ≥ фон, иначе Y·255/фон`. Цвет сдвигается на `Y' − Y`. Сдвиги двух страниц сводятся с переходом
   3 мм за краем области. Применяется и к итогу. Целиком цветные страницы (`colour_pages` FULL) не трогаются.
2. **Разбор текста** каждой страницы выпрямленного кадра: `page_layout.text_blocks.analyse_gray` с движком по
   краске (CPU, ~2 с на страницу), без забеливания цвета. Вырезка — прямоугольник страницы плюс 5 мм, но не дальше линии корешка (иначе
   концы строк соседней страницы срастаются со своими).
3. **Выборки** (`text_field.py`):
   - оси строк от 25 мм — в горизонталь на медианной высоте строки;
   - выровненные стороны блоков — в вертикаль. Стороны одной отбивки колонки (медианы ближе 3.5 мм) получают общую
     цель; короткие, от 8 мм, идут в дело, если группа длиннее 25 мм.
   - на концах строк и сторон выборки гуще (через 1 мм на последних 8 мм): самые сильные изгибы — на концах.
   - дубли из пересекающихся блоков (выборки разных строк в радиусе 2 мм) делят вес.
4. **Поле** — своё у каждой страницы, на линии разреза разрыв (общее тянуло изгиб одной страницы в концы строк
   другой). Сетка 3–4 мм, тонкая пластина с анизотропной жёсткостью:
   - вдоль строк длина изгиба 10 мм в теле страницы и 3–4 мм у корешка (зона 15 мм плюс переход 15 мм);
   - поперёк строк — 8 мм (при 15 сноски наследовали изгиб текста над ними — 01/IMG_1040). Систематический загиб концов многих строк подряд поле повторяет, а одну выбившуюся
     строку — нет. При гибкости поперёк строк начала строк у корешка мялись.

   Робастность — Хьюбер 0.5 мм и отсев выборок с остатком больше 3 мм. Страница с менее чем 8 строками и цветная
   прижимаются к нулю. Потолок поля — 8 мм.
5. **Итог** — одна выборка из выровненного итога v2 по составной карте: точка холста + поле → Кунс. Составная карта
   считается по сетке 4 px с доводкой бикубически, у шва страниц и сторон областей — точно (отличие до 0.6 px). За
   краем итога v2 — продление края с размытием, растущим с удалением (σ = 0.5 × удаление, до 15 мм); прежнее отражение
   зеркалило текст у края на поле (01/IMG_1049).

Ещё:
- **Цветная страница** (без освещения и поля): FULL или доля насыщенных пикселей ≥ 0.2. Обложки ХиП с белыми плашками
  — медиана цветности 8–11 (ниже FULL), насыщенного 45–47 %; страницы с цветной печатью и фото — до 9 % (546 страниц).
- **Разбор строк — без забеливания цвета**: в ХиП и ПХ «цветные элементы» — в основном цветная печать, а фото
  чёрно-белые; забеливание насыщенных пикселей стирало синий текст (01/IMG_1088: длинных осей 12 вместо 23, заголовка
  нет) и от ложных строк на фото не защищало. Ложные строки отсекают длина (от 25 мм) и робастный отсев.
- **Тонкий шрифт ПХ 1975**: копия для разбора утолщается по вертикали на 0.25 мм, иначе строки уходят в «черты».
- **Линейки** (одинокие черты, линейки таблиц, черты над сносками, двойные линейки колонтитулов; длиннее 15 мм,
  толщина до 1.8 мм — замер по 83 кадрам; терпят изгиб к концу — краска расширяется поперёк на 0.35 мм перед открытием)
  — опоры поля: горизонтальные — как строки, вертикальные — как стороны блоков. Отбрасываются линейки у края страницы
  (ближе 4 мм — край тени), внутри line art и растра, а вне таблиц — не сироты (к краске линейки примыкает что-то
  дальше 0.8 мм поперёк: засечки оси графика, стрелки, буквы). Стороны ЗАМКНУТОЙ РАМКИ (вокруг полосы, колонки,
  врезки: краска компоненты — только полосы вдоль сторон её прямоугольника) берутся без проверки сироты, а у края
  страницы — если снаружи бумага (`_is_frame`, `_paper_outside`).
- **Колонка номеров оглавления** — правая выровненная сторона блока `number_column` детектора (`page_numbers.py`),
  сквозь заголовки разделов; правые стороны блоков по концам отточий в опоры не идут.
- **Рисунки, растр и таблицы — преграды разбора** (`region_barriers`, `barrier_cuts`): текст, упёршийся в них боком,
  — отдельный блок (01/IMG_0986). Страница с 2–7 строками (титул) — режим поля SPARSE: поле у опор, вдали нули.
- **Опора строк — базовая линия** (`LineAxis.base_points`, `text_field.line_curve`), а не ось центра масс.
- **Растр, таблицы, line art** — детекторы `page_layout` по пикселям (без surya), по странице после Кунса. Строки,
  стороны и линейки внутри line art и растра в опоры поля не идут (подпись на схеме, штриховка — часть рисунка). На
  листах — полупрозрачные рамки.
- Поле у корешка: в пустой полосе между текстами страниц поля двух страниц смешиваются плавно (излом линии разреза на
  08/IMG_0329); высота цели строки — свободная, со штрафом за масштаб по вертикали (иначе начала строк у корешка
  сжимались вместе с буквами — 03/IMG_0127); 3 прохода «разбор → поле».
- Все наборы прогона — в одном пуле (`--set …` повторяется).

Листы — `debug/<шаг>/<набор>/<кадр>.jpg`: `01_illumination`, `02_analysis` (разбор и стрелки выборок ×5),
`03_field` (модуль поля и деформированная сетка), `04_result` (итог v2 с областями | Кунс | итог: оси строк, стороны,
линейки, линия разреза, меры в шапке). Меры (`measure.py`): размах оси строки по высоте, наклон, размах выровненных сторон. Они считаются тем
же детектором и потому немного «свои»; смотреть их надо вместе с листами.

## Запуск

```bash
SAMPLE=25 run_scripts/scan_cropping/run_page_rectify_spline_frames.sh   # выборка, листы «было | стало»
run_scripts/scan_cropping/run_page_rectify_spline_frames.sh             # все кадры трёх наборов
SAMPLE=25 run_scripts/scan_cropping/run_page_rectify_text.sh           # второе преобразование: выборка
run_scripts/scan_cropping/run_page_rectify_text.sh                     # все кадры
uv run python -m research.page_rectify run --input-dir … --cache … --v2-output … --output … [--debug …] [--sample N]
uv run python -m research.page_rectify text-run … [--field-step-mm 4 --field-smooth-mm 10 --gutter-smooth-mm 4 --across-smooth-mm 15]
uv run python -m research.page_rectify relayout --root … [--dry-run]    # прежняя раскладка → output/, debug/, summary/
```

Выход: `$SPLINE_RECTIFIED_SAMPLE_WORK` и `$SPLINE_RECTIFIED_WORK` (`common.sh`), у второго преобразования —
`$TEXT_RECTIFIED_SAMPLE_WORK` и `$TEXT_RECTIFIED_WORK`. Внутри одна `output/<набор>/…`, одна `debug/…` и
`summary/<набор>.csv`; у ХиП набор — `hp_1991/<выпуск>`. Лист `debug/<кадр>.jpg`: слева итог v2 с областями и сеткой изолиний `u, v`
(шаг 10 %, за областью — приглушённо), справа выпрямленный кадр с прямоугольниками и той же, уже прямой, сеткой.
В сводке: размеры страниц в мм, разница высот у корешка, наибольший изгиб стороны.

Тесты: `uv run pytest tests/research/page_rectify -q`.
