# research/spread_lines — прямые разворота

Прямая-разделитель между страницами разворота и прямые-ограничители внешних краёв страниц по кэшу прогона
`scan_cropping.v2` (без GPU). Ядро — `ocr_utils/scan_cropping/v2/spread_lines.py`; в v2 линии рисуются на основном
оверлее и на шаге `07_lines` (`--debug-steps`), итог кадра от них не зависит (TIFF побайтно те же, 23 кадра проклейки).

## Что строится

- **Разделитель** — четыре способа (`SpineMethod`): `quad_mid` — через середины концов внутренних сторон трапеций;
  `gap_mid` — Хубер по середине между кромками масок страниц по строкам; `gap_mid_run` — то же по сплошному участку
  маски от тела страницы; `fold` — Хубер по линии сгиба по яркости бумаги (`research/page_cutting/fold.py`). Боевой —
  `auto` (умолчание v2 с 2026-10-21): `gap_mid`, а если его наклон дальше 1° от `quad_mid` — `quad_mid`; картинки —
  в папке `auto/`, в подписи — способ, на котором кадр остался.
- **Край книги** с каждой стороны — Хубер по крайним точкам грубой маски книги в средних 80 % высоты страниц; строки
  у рамки кадра (ближе 2 мм) и у руки / пальца (5 мм) отброшены; если отброшено больше половины строк не у рамки —
  прямая по всем строкам не у рамки. Край «в кадре» — у рамки меньше 5 % строк.
- **Ограничитель** — прямая по внешней кромке бумаги страницы (99.5 % кромки внутри); наклон — края книги, если он в
  кадре; иначе виртуальный (`VirtualRule`, по умолчанию `spine` — параллельно разделителю; `mirror` —
  `2·θ_разделителя − θ_противоположного края`, `opposite` — как противоположный край).

## Запуск

```bash
./run_scripts/scan_cropping/run_spread_lines.sh                     # три набора: run → select → evaluate
uv run python -m research.spread_lines run --cache <кэш v2> --out <папка> --jobs 16
uv run python -m research.spread_lines select --out <папка>          # симлинки по поясам расхождения и виртуальные
uv run python -m research.spread_lines evaluate --out <папка>        # ошибка правил виртуального наклона
```

Выход: `lines.csv`, `<способ>/<подпапки>/<кадр>_07_lines.jpg`, `compare/…_spine.jpg` (полоса у корешка, все способы),
`select/`.

## Результаты (2026-10-21)

| Набор | Разворотов | Край книги за кадром | Расхождение разделителей, мм (медиана / p90 / max) |
|---|---|---|---|
| проклейка ПХ 1975 (`gutter_strip`) | 23 | 0 | 3.42 / 7.83 / 10.2 |
| пак-4 ПХ 1975 | 1024 | 0 | 0.31 / 1.17 / 25.7 |
| пак-6 v6 МТС/РИСК | 2458 | 567 кадров с виртуальным | 0.51 / 2.93 / 65 |

- **Разделитель.** Три способа по маскам на обычных разворотах совпадают (до 1 мм). `fold` отвергнут как есть: на
  обычных разворотах цепляется за линейки таблиц и рамки (пак-4 05/IMG_0073 −7.2°, 09/IMG_0016, 07/IMG_0065) и
  пересекает полосу проклейки (12/IMG_0066). На проклейке у полосы два сгиба: способы по маскам садятся на тот, где
  SAM 3 кончил страницу (чаще левый), `fold` — на самый тёмный (чаще правый). Граница страниц на проклейке — середина
  полосы (решение 2026-10-21, пока): `gap_mid` даёт её сам, когда полоса не входит ни в одну маску страницы; куски
  полосы в маске сдвигают его к дальнему сгибу — как часто, на `gutter_strip` ещё не отсмотрено.
  `gap_mid` сбивается рваной маской (05/IMG_0021 +1.41° против −0.5° у остальных), `gap_mid_run` и `quad_mid` — нет.
- **Виртуальный наклон** (`evaluate`, кадры с обоими краями книги в кадре, предсказание одного края по другому):
  медиана / p90 ошибки — пак-4: зеркально 0.90° / 2.11°, параллельно разделителю 0.58° / 1.97°, как противоположный
  1.46° / 2.81°; пак-6: 0.68° / 1.85°, 0.65° / 1.40°, 1.25° / 1.98°. Параллель разделителю не хуже зеркала, а на
  поворотах книги лучше (МТС 1991/01 IMG_0551: зеркало −3.9°, кромка страницы ≈ −1.1°, разделитель −2.5°).
- Кожа по цвету ловит красные переплёты (МТС 1991/01 IMG_0576 — весь край книги «в руке»): рукой считается только кожа,
  касающаяся закраса пальца (`finger_hands`); ложных «за кадром» стало 567 вместо 757. Если палец лежит на таком
  переплёте (МТС 1991/06 IMG_0316), весь переплёт связан с пальцем: рукой — только кожа в 15 мм от закраса (левый край
  книги −5.88° по 57 точкам → −1.22° по 1188).
- **Приподнятая страница** (пак-6, 860 кадров с одной приподнятой): `gap_mid` и `quad_mid` расходятся мало (медиана
  0.18 мм, p90 0.48 мм, больше 2 мм — 9 кадров), но где расходятся, `quad_mid` уходит на изгиб приподнятой страницы,
  а `gap_mid` держит стык: РИСК 1991/01 IMG_0615 (4.9 мм), МТС 1990/04 IMG_1141 (2.3 мм), МТС 1991/07 IMG_0857.
  Поэтому боевой — `auto`: `gap_mid` с откатом на `quad_mid` при рваной маске (05/IMG_0021, разница наклонов 1.9°) и
  на обложках (РИСК 1993/01 IMG_0281, `gap_mid` −12.9°).
