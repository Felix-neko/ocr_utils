# research/sam3_ink_fill — SAM 3 по кадру без крупной краски

**Задача.** На страницах с толстой напечатанной рамкой SAM 3 принимает рамку за край листа: бумага за рамкой, до
настоящего края, в маску не попадает (МТС 1991/05 IMG_0250, правая страница). Стенд закрашивает крупную краску на копии
кадра сегментации и прогоняет SAM 3 второй раз. Итоговая бумага — прежняя ∪ бумага по кадру без краски.

## Как закрашивается краска (ядро — `ocr_utils/scan_cropping/v2/ink_fill.py`, здесь реэкспорт `ink.py`)

1. **Вся краска.** Темнее локального фона бумаги (закрытие серого диском 30 px) на ≥ 30 уровней, хрома Lab < 25,
   внутри грубой маски книги.
2. **Крупная краска:**
   - открытие диском 7 px: полосы шире ~1 мм, буквы уходят;
   - плюс длинные тонкие линии: компонента длиной ≥ 100 px (~15 мм), тонкая (≤ 8 px) или почти пустая внутри
     (контур, заполнение ≤ 0.15). Внутренняя тонкая линия двойной рамки IMG_0663 — 3–4 px, без этого она оставалась.
3. **Без одиночных полос и бледных пятен:**
   - удлинение повёрнутой рамки компоненты ≥ 8 — тень и тонкая линия края страницы на стыке с торцом, линии торца,
     тень у корешка. Без этого торец сливался со страницей, и второй проход SAM 3 брал его (МТС 1990/03 IMG_1025,
     IMG_1034, МТС 1991/05 IMG_0182, РИСК 1991/05 IMG_0619: до +103 тыс. px торца). Рамка — замкнутый контур
     с удлинением ~1–2, она остаётся;
   - 90-й перцентиль «темнее бумаги» < 60 — серая рваная тень у края страницы (35–56) против печати (63–250).
4. **Только в окружении бумаги.** Кольцо 2 мм вокруг пятна должно быть ≥ 80% светлой бумагой: в книге, не фон, не
   тёмное и не темнее 70% типичной бумаги кадра. Последнее условие нужно, потому что на сплошной тёмной крышке
   переплёта «темнее локального фона» не срабатывает. Щель и тень у корешка, карманы коврика, крышка и тёмный торец
   не закрашиваются.
5. **Закрас.** Запас 3 px, Telea радиусом 9.
6. **Добавка второго прохода** принимается только кусками, касающимися закрашенной краски: бумага за рамкой
   начинается от рамки. Остальное — колебания SAM 3 на кадре без краски (МТС 1990/03 IMG_1084: +495 тыс. px торца
   приподнятой страницы).

## Итоги (10 кадров пака-6, 2026-10-12)

| Кадр | Бумаги добавлено объединением, px сегментации | Кадр без краски сам по себе потерял бы |
|---|---|---|
| МТС 1991/05 IMG_0250 (рамка) | +366 424 — поля до края листа на обеих страницах | 681 |
| РИСК 1991/05 IMG_0663 (двойная рамка, приподнятая страница) | +6 909 | 29 068 (до тонких линий — 395 899) |
| остальные 8 контрольных | 0 … +16 888 | до 22 385 |

Почему объединение, а не замена: SAM 3 по кадру без краски местами берёт лист хуже прежнего. Объединение ничего
не теряет.

**Открыто:**
- **Telea размазывает непойманный полутон** у края широких полос: тёмные пятна в углу IMG_0250, в логотипе IMG_0663.
  Возможная правка — заливать оценкой цвета бумаги по кольцу.
- **Закрашивается лишнее.** Тонкие линии цепляют строки у корешка, слитые с тенью (IMG_0591), и торец с бумагой
  вокруг. Бумаги это пока не добавило.
- **Нет прогона по всем кадрам** трёх проверочных папок.

## Запуск

```bash
uv run python -m research.sam3_ink_fill run \
    --cache /mnt/hotstore/scan_processing/scan_cropping_v2/check2_2026-10-12/cache/МТС/1991/05/IMG_0250 \
    --out-dir /mnt/hotstore/scan_processing/sam3_ink_fill/try3
```

На вход — папки кадров из кэша scan_cropping v2 (`seg.png`, `book.npz`, `sam3.npz`). Выход:
- листы «было | стало» (`<кадр>.jpg`);
- маски (`<кадр>.npz`: `ink`, `raw`, `inst`, `paper`, `alone`).

GPU: SAM 3 1288 px. Параллельно с боевым прогоном v2 не запускать: не хватает видеопамяти.
