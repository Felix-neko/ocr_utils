# research/spread_ocr — текст разворотов и пары кадров двух съёмок по тексту

Стенд для случая «один и тот же переплетённый выпуск снят дважды разными людьми» (РИСК 1991 №5: пак-6 от Лены
и пак-7 от Бори). Для каждого кадра читается левая и правая полоса разворота, затем полосы базы сопоставляются
с полосами донора по тексту — независимо от ключевых точек (AKAZE/SIFT, `research/cut_lines`).

## Как работает

1. **Разрез разворота** (`split.py`). Маска бумаги на ¼ масштаба: яркое и не насыщенно-красное (фон — чёрный мат
   или красная ткань; синяя обложка — тоже «бумага»). Сгиб — столбец средней полосы бумаги (35–65 % ширины)
   с наименьшей **медианой** яркости по строкам: буквы медиану не трогают, тень сгиба темнит весь столбец.
   Полосы режутся с полем 40 px за сгиб, наклон выравнивается перебором угла ±8° по дисперсии проекции краски.
2. **OCR** (`ocr.py`). tesseract `rus+eng`, `--psm 3` (автоматический разбор колонок), слова с уверенностью ≥ 40
   и хотя бы одной буквой/цифрой; строка остаётся, если в ней есть слово из трёх букв или число.
3. **Номер страницы.** У этого журнала номер стоит на правом конце линейки колонтитула у **обеих** полос: у левой —
   у сгиба (часто обрезан: «16» → «6»), у правой — у наружного края. Сначала — самый правый числовой токен строки
   колонтитула из полного прохода; иначе — отдельный проход `--psm 11` по полосе колонтитула полного кадра
   (у левой полосы — с запасом 250 px за сгиб). Номер принимается при верной чётности (левая чётная) и в пределах
   1..112. Пара номеров кадра согласуется (правая = левая + 1, при споре верится правой), недостающий выводится
   (`page_number_source = spread`).
4. **Сопоставление** (`match.py`). Текст нормализуется до строчных букв (переносы склеены), из него — шинглы по
   6 букв; сходство двух полос — вложенность `|A∩B| / min(|A|,|B|)` (крупный план видит часть полосы). Для каждой
   полосы базы — лучшая полоса донора и запас уверенности до второй (второе место ищется только среди полос
   донора с другим содержимым, чтобы пересъёмки не съедали запас). Для кадра — кадр донора с наибольшей суммой
   «левая↔левая + правая↔правая».
5. **Нумерация донора по порядку.** Донор снят по развороту на кадр подряд, поэтому левая = 2·k + сдвиг; сдвиг —
   мода прочитанных номеров (своих и базы через пару по тексту). Это даёт номер каждой полосе, даже нечитаемой.

## Команды

```bash
uv run python -m research.spread_ocr ocr --set lena=<папка> --set borya=<папка> --out <выход> --jobs 12
uv run python -m research.spread_ocr match --out <выход> --base lena --donor borya --akaze-pairs <pairs.csv>
```

Готовый прогон — `run_scripts/spread_ocr/run_risk_1991_05.sh` (~100 с на 169 кадров при 12 воркерах).
Повторный `ocr` берёт полосы из `json/` (кэш), для пересчёта — удалить `json/`.

## Выход (`/mnt/hotstore/scan_processing/spread_ocr/risk_1991_05/`)

| Файл | Что |
|---|---|
| `pages.csv` | set, frame, side, page_number, page_number_source (page / band / spread), header, n_lines, first_lines, last_lines, ocr_confidence |
| `text/<set>/<кадр>_<сторона>.txt` | полный текст полосы |
| `json/<set>/…json` | кэш полосы: строки, номер, угол выравнивания, абсцисса сгиба |
| `pairs_by_text.csv` | по полосам базы: лучшая полоса донора, номера (база, донор, по порядку донора), сходство, второе место, уверенность |
| `pairs_compare.csv` | по кадрам базы: пара AKAZE, пара по тексту, согласие, лучшие полосы, страницы по порядку донора |
| `donor_sequence.csv` | кадр донора → номера левой и правой полосы по порядку, голоса за сдвиг |
| `similarity.npy` | матрица сходства полос база × донор |

## Результат на РИСК 1991 №5 (2026-10-11)

- Полос с текстом (≥ 10 строк): Лена 213 из 220, Боря 116 из 118; медианная уверенность tesseract ~92.
  Полоса в фокусе читается почти без ошибок, расфокусированная — обрывками, но для сопоставления хватает.
- Номера прочитаны прямо у 85 полос Лены и 32 полос Бори (у левых — плохо: номер уходит в сгиб); по порядку
  донора: левая = 2·k − 2 (86 из 111 голосов), кадр Бори IMG_0064 — с. 0–1, IMG_0120 — с. 112–113.
- 107 из 110 кадров Лены нашли пару; все 59 кадров Бори покрыты. Пары AKAZE совпали с текстовыми во всех 91
  случаях, где обе есть; 18 кадров Лены без пары AKAZE — вторые снимки разворотов (фокус на другой полосе),
  их развороты в съёмке Бори есть. Без пары по существу: IMG_0701 (пустой форзац) и IMG_0702 (закрытый том);
  у IMG_0701 пара AKAZE (IMG_0104) ложная.

## Ограничения

- Обложки и форзацы почти без текста: на внутренних сторонах передней и задней обложки одна и та же реклама,
  IMG_0537 → IMG_0063 и IMG_0700 → IMG_0121 разведены по тексту (0.80 против 0.12), но опора слабее, чем у
  полос с текстом; пустые полосы не сопоставляются никак. Номера по порядку у обложек (−2, 114) условны.
- На IMG_0702 (закрытый том) в номер попали цифры наклейки («24/25») — мусор.
- Номер левой полосы у сгиба читается плохо; надёжнее нумерация по порядку донора.
