# Валидационные эталоны

Страницы, по которым пользователь глазами решил, испортила коррекция геометрии FineReader
страницу или нет. Пополнять именно эти файлы; `run_scripts/geometry_regression/labels.csv`
(формат `pdf,page,label,note` для `report --labels`) — производная, собирается из них.

`pack1/fr_correction_bad.csv` — коррекция сделала хуже, страницу брать из PDF без коррекции;
`pack1/fr_correction_good.csv` — коррекция помогла или «чуть испортила, но выправила больше»,
берём версию с коррекцией (сюда же ложные тревоги детектора).

Формат — TSV: `название<TAB>путь<TAB>краткая аннотация` (название — `full_ГГГГ_НН с.N`, путь —
картинка «было | стало» прогона, на котором страница смотрелась (v7, иначе v6); если ни один
прогон страницу не флаговал — PDF с коррекцией и номер страницы, `…pdf#page=N`).
