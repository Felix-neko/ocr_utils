# research/newspaper_crop — зона копирования на фотосканах газет

Стенд, на котором сравниваются способы выделить на фотоснимке газетной полосы (ЭГ, RAF Fujifilm, постраничная
съёмка подшивки) область, которую отдают в ScanTailor:
- в область попадает только газетная бумага этой полосы, печать не срезана;
- обложка, крышка подшивки, пол, соседняя полоса и пальцы остаются снаружи;
- область дорисовывается до прямоугольника.

Отчёт: `reports/newspaper_crop_zone.md`. Прогон целиком: `run_scripts/newspaper_crop/run_sample_eg_1969_1970.sh`.

## Конвейер

```
RAF → встроенное JPEG-превью (frames.py)
    → [пальцы: scan_cropping.finger_removal + LaMa → nofinger/]
    → движок: грубая маска листа (engines.py)
    → хвост: чистка, четырёхугольник с перспективой (zone.py)
    → дорисовка не-бумаги, прямоугольник «по месту» или выпрямленный (fill.py)
```

Лучший вариант: `sam2_box` на кадрах без пальцев. Это SAM2.1 Hiera-L с подсказками «бокс во весь кадр с отступом 1%» и «точки 3×3 в центре», из кандидатов берётся самая крупная маска с оценкой ≥ 0.5.

## Модули

| Модуль | Что делает |
|---|---|
| `frames.py` | исходные папки, выборка `sets/sample.csv` (`group, path, skip, note`), извлечение превью RAF с EXIF-поворотом, кэш на SSD |
| `engines.py` | движки маски листа: `sam2_points`, `sam2_box`, `sam3_text`, `birefnet`, `dino_kmeans`, `dino_sam2`, `color`, `scan_cropping`, `ink_hull` |
| `zone.py` | чистка маски, охватывающий четырёхугольник (`minAreaRect` → Хубер по точкам стороны без рамки кадра → сдвиг до квантиля 0.995), меры зоны |
| `ink_guard.py` | строки печати по рецепту `page_layout/orientation/detectors/ink_axis.py`; движок «оболочка печати» и страж «строки вне / в дорисовке» |
| `fill.py` | дорисовка не-бумаги (Telea на ¼ масштаба), прямоугольник `in_place` / `warp` |
| `overlay.py` | оверлей зоны: не бумага, дорисовка, отрезанное, четырёхугольник, пальцы; оверлей классификатора «свой лист / чужое» (`surface_overlay`); легенда в поле |
| `spine_cut.py` | отрезка за складкой корешка: складка у каждой стороны выпрямленной полосы (`spread_defects.fold_line`, A+3 — минимум уровня бумаги, путь; без строк и цветной печати), приём по «за линией соседняя полоса», перенос стороны и маска «за складкой» |
| `text_guard.py` | защита своей печати: зазор 10 px у строк в листе, охват четырёхугольником (стороны по складке не двигаются), зазор вне листа — ровный цвет бумаги |
| `content_tilt.py` | наклон сторон по содержимому: строки, края колонок, линейки → точки схода и локальная оценка у стороны |
| `inner_edge.py` | кромка верхнего листа у стороны: самая внутренняя прямая ступень яркости до печати (проба, отвергнута как правило) |
| `surface_clf.py` | классификатор «свой лист / чужое»: участки у сторон, признаки DINOv2-base и цвета, разность к своей бумаге, логистическая регрессия вне выборки по кадрам, граница стороны |
| `tilt_cvat.py` | эталон наклона в CVAT: отбор кадров, задача с полилиниями текущих сторон, забор в `sets/tilt_gt.csv` |
| `sharpness.py` | цена выпрямления для резкости: участки печати до и после гомографии (DOM, крутизна края), варианты интерполяции, апскейл ×2, RAW |
| `compare.py` | сводка прогонов и IoU масок листа между прогонами |
| `cli.py` | команды (ниже) |

## Команды

`uv run python -m research.newspaper_crop <команда>`:

| Команда | Что делает |
|---|---|
| `previews [--all-frames] [--jobs 8]` | кэширует превью: выборки или всех RAF двух папок |
| `contact-sheet --group G` | листы миниатюр группы, чтобы глазами отобрать трудные кадры и обложки |
| `select --per-group 25 --extra G/имя ...` | равномерная выборка плюс трудные кадры; пометки `skip/note` сохраняются |
| `fingers` | маска пальцев и превью с закрасом (`nofinger/`); раздутая маска не заходит на печать с зазором `--guard-px` (`text_guard.finger_protect`: глифы цепочкой, наклонные строки тоже), зона пальца перед LaMa не высветляется; `--keys` — только эти кадры |
| `run --engine E [--source nofinger --tag T]` | прогон движка: `zones/`, `overlays/`, `summary.csv` |
| `rezone --run R` | пересобирает зоны из сохранённых сырых масок, без GPU (после правки хвоста) |
| `vote --runs A --runs B --runs C --name N` | комбинация масок голосованием большинства |
| `sheets --run R`, `corner-sheets --run R` | листы для отсмотра: миниатюры; четыре угла каждого кадра крупно |
| `compare-sheet --runs ... --key ... --name N` | лист «движки рядом» по выбранным кадрам |
| `spine-cut [--run R --name N]` | отрезка за складкой корешка по зонам прогона → `runs/spine_cut/` (`sides.csv`, оверлеи) |
| `sharpness [--raw/--no-raw] [--jobs 6]` | замер резкости выпрямления по выборке → `sharpness/tiles.csv`, `summary.csv` |
| `copy-out --run R [--key ...] [--guard/--no-guard]` | прямоугольники под ScanTailor `in_place` и `warp` плюс склейка; с защитой печати из `guard-eval` |
| `guard-eval [--run R --guard-px 10]` | зазор и охват своей печати → `runs/<R>/guard/`, `guard.csv` |
| `tilt-candidates [--run R]` | расхождение сторон с содержимым по всем кадрам → `runs/<R>/tilt_sides.csv` |
| `surface-crops [--name gt]`, `surface-eval [--tau 0.5 --min-share 0.2]` | участки у сторон кадров эталона и признаки DINOv2 → `surface/<name>/`; оценка классификатора вне выборки и ошибка сторон |
| `surface-overlays [--name gt]` | оверлеи классификатора по кадрам эталона: участки по вероятности, эталон, граница по классификатору, конвейер; вырезки крупно вдоль сторон с ошибкой > 20 px → `surface/<name>/overlays/` |
| `tilt-export --extra G/имя`, `tilt-import` | эталон наклона сторон: задача CVAT и забор в `sets/tilt_gt.csv` |

Выход — `/mnt/hotstore/scan_processing/newspaper_crop/`. В исходные папки на Я.Диске ничего не пишется.

## Веса

- SAM2.1, BiRefNet, DINOv2 — с Hugging Face. BiRefNet требует `timm` и `kornia`.
- SAM 3 — gated `facebook/sam3`. Лежит в `finger_models/sam3/sam3.pt` (вне git); взят с зеркала ModelScope `facebook/sam3`, SHA-256 `9999e234…8c9e` совпадает с официальным.
- Стек `scan_cropping` — `finger_models/`.

## Пример

```python
import numpy as np
from research.newspaper_crop.zone import build_zone

mask = np.zeros((2208, 1472), bool)
mask[100:2150, 20:1450] = True        # маска листа от движка на рабочем масштабе (½ превью)
zone = build_zone(mask)
zone.quad        # (4, 2) вершины четырёхугольника копирования, по часовой стрелке
zone.fill_frac   # доля четырёхугольника, которую надо дорисовать
```
