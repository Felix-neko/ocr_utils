# text_layer_fix — чистка и дополнение текстового слоя FineReader для повёрнутого текста

Зачем и что делаем — в докстринге `__init__.py`. Отчёт по прогону — `reports/text_layer_fix.md`,
оверлеи к нему — `reports/text_layer_fix/` (вне git).

## Команды

```bash
# Обзор слоя всех PDF пака (только чтение): формы спанов, повёрнутые матрицы, привязка → survey.csv
./run_scripts/text_layer_fix/run_survey.sh

# Выборка страниц: зоны, вердикты по словам, чтение зон → cache/, pages.csv, words.csv, zones.csv
./run_scripts/text_layer_fix/run_sample.sh            # ~1050 страниц, 12 воркеров, ~5 мин

# Второе мнение surya (GPU, один процесс) по зонам с ненадёжным чтением; JSON кэша обновляется
./run_scripts/text_layer_fix/run_second_opinion.sh

# Пересчитать вердикты слов по кэшу (после surya или смены порогов)
uv run python -m research.text_layer_fix reclassify --pdf-dir ... --out-dir ...

# Исправленные копии PDF (исходники не трогаются) → pdf/, fix.csv со сверкой каждой страницы
./run_scripts/text_layer_fix/run_fix.sh

# Оверлеи → overlays/<категория>/
./run_scripts/text_layer_fix/run_overlay.sh

# Точность и полнота источников line art против ручной разметки → lineart_eval.{csv,json}
./run_scripts/text_layer_fix/run_eval_lineart.sh

# Сравнение с языковой моделью (нужен OPENROUTER_API_KEY) → llm_compare.{csv,json}
./run_scripts/text_layer_fix/run_llm_compare.sh

# Сводка для отчёта
uv run python -m research.text_layer_fix report --out-dir /mnt/SYSTEM/raw/mts/pack1_text_layer_fix/pack1_v1
```

Пути — в `run_scripts/text_layer_fix/common.sh`; выход прогона — `/mnt/SYSTEM/raw/mts/pack1_text_layer_fix/<версия>/`.

## Как устроено

| Модуль | Что в нём |
|---|---|
| `text_layer.py` | Разбор потока содержимого до слов (спан `/Span <</MCID n>>` = слово) и глифов; привязка к символам `rawdict` по началу глифа; метрики шрифтов через pikepdf; строки дерева структуры |
| `raster.py` | Рендер страницы в родном разрешении образа (600 dpi), рамки дополнительных картинок FineReader (`figures`), перевод pt ↔ px |
| `zones.py` | Зоны повёрнутого текста: таблицы детектора → сетка → ориентация ячеек (`rotated_text.tables`); боковой текст вне таблиц по соседям глифов; сторона по tesseract. Прямой текст без слоя вне таблиц (`upright_zones`): горизонтальные цепочки, под которыми нет слов слоя — только чтение и вставка |
| `docstrum.py` | Направление на ближайших соседей глифа: вертикальные цепочки → рамки боковых подписей; те же цепочки по транспонированному растру → прямые строки (`cluster_lines`) |
| `classify.py` | Вердикт по слову: KEEP / KEEP_ROTATED / DELETE / SANITIZE / SUSPECT — по перекрытию рамки слова с зонами; словарная страховка в непрочитанных зонах |
| `ocr.py` | Чтение зон tesseract-ом; сравнение с прямым чтением снимает ложные «боковые» ячейки («ШТ.») |
| `second_opinion.py` | Surya по ненадёжным зонам в родителе, фильтр выдумок из `rotated_text` |
| `rewrite.py` | Правка потока: вырезание `BT…ET` внутри спана, усечение слова, вставка невидимого повёрнутого текста своим шрифтом одним потоком; сверка |
| `fixer.py` | Исправленные копии PDF по кэшу |
| `pipeline.py` | Одна страница от растра до вердиктов и чтений; JSON кэша |
| `lineart_eval.py` | Точность/полнота источников line art против ручной разметки на no-geo PDF |
| `llm_sanitize.py` | Сравнение геометрического вердикта с вычёркиванием мусора LLM |
| `overlay.py`, `report.py` | Оверлеи и markdown-сводка |
| `pages.py` | Выборка страниц и привязка «страница PDF ↔ полоса» по базе-зонду |

## Что важно знать о слое FineReader

* Один поток содержимого на страницу; каждое слово — спан со своим `Tm` (растяжение под ширину
  слова), каждый глиф — `Tj` + `Td`. Страничный сдвиг `cm` лежит внутри первого спана — удалять
  спан целиком нельзя, только `BT … ET`; тогда и дерево структуры остаётся валидным.
* Повёрнутый текст FineReader чаще всего пишет горизонтальной россыпью из 1–3 знаков; но иногда
  (39 страниц пака, 220 слов) — правильно, с повёрнутой матрицей: такие слова не трогаются.
* Куски, которые FineReader счёл картинкой (чертежи, схемы, а иногда полоска вертикального текста),
  лежат отдельными JBIG2-образами; текстового слоя на них нет вовсе — там текст только добавляется:
  боковой (`LINE_ART_LABEL`) и прямой (`LINE_ART_UPRIGHT`); прямой текст без слоя вне схем —
  `STANDALONE_UPRIGHT`, прямые ячейки таблиц без слоя — `TABLE_CELL_UPRIGHT`.
* Текст обрезанной части образа FineReader кладёт за CropBox (глифы вне страницы); `rawdict` их не
  видит, в правке они не участвуют.
* MediaBox страницы и её образ могут не совпадать — координаты считаются через
  `page.transformation_matrix`, а не переворотом по высоте.
