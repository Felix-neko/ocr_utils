# research/flush_split — разрез текстового блока по смене выключки

Стенд для правила `ocr_utils/page_layout/text_blocks/flush_split.py`: подпись авторов под статьёй, «г. Город»,
автор цитаты — отдельные текстовые блоки, а не хвост абзаца. Боевой код меняется только в `flush_split.py` и
`regroup._rejoinable`; способ переключается `FlushSplit` (`off` / `align` / `align_gap` / `align_right` / `align_right_gap`, по умолчанию с 2026-10-31
`align_right_gap`). В `run` способ без суффикса — без барьеров линеек (`RuleBarriers.OFF`, как в прежних прогонах),
`<способ>:ink` — с вертикальными линейками краски (умолчание разбора).

## Правило (способ `align_right`)

Сформулировано пользователем (2026-10-30):

- у абзаца по формату последняя строка начинается у левого края (или с абзацным отступом) и занимает часть
  ширины — она остаётся в блоке;
- строка, сменившая выключку с «влево / по формату» на «вправо», — первая строка нового блока, подтверждения
  (промежуток, кегль, жирность) не нужны.

Сверх этого по множеству:

- смену решает **первая** строка нижней группы: под фамилией бывает регалия почти во всю ширину, под автором
  цитаты — следующая цитата (ХиП 1991/04 IMG_0207_L, 05/IMG_0332_R);
- абзац над строкой вправо — и короткий: одна полная строка и концовка точно у левого края (цитата в две строки);
- кусок строки, разорванной широким пробелом выключки по формату, на одной высоте с другим рядом — не строка вправо
  (03/IMG_0082_L «ст. 214», 04/IMG_0239_R, 04/IMG_0252_L);
- возврат «подпись → строка влево / абзац точно у левого края» («г. Город», следующая цитата) — без подкреплений;
  «подпись → абзац с отступом» (ответ редакции под письмом читателя, 01/IMG_1075_L) — только при промежутке
  ≥ `FLUSH_GAP_PITCHES` шага: так же выглядит лесенка регалий;
- внутри подписи (группа начата строкой вправо, правые края совпадают) разный набор склейке не мешает
  (`flush_split.signature_continues` в `regroup._rejoinable`): жирная фамилия и светлые регалии — один блок.

## Данные

- вырезки холста Кунса ХиП 1991, выпуски 01–07 (1106 страниц): `/mnt/hotstore/scan_processing/line_art_boxes/hp_1991/canvas/`
  (`python -m research.line_art_boxes canvas`);
- выход стенда — `/mnt/hotstore/scan_processing/block_split/v7/`.

## Ход

```bash
# 1. tesseract (rus, psm 3) по всем вырезкам: CSV строк с рамками в мм (~20 мин на 12 процессах)
uv run python -m research.flush_split ocr --jobs 12
# 2. концы статей и строки-подписи: хвосты текста на чтение (candidates_NN.md)
uv run python -m research.flush_split candidates
# 3. чтение глазами по тексту → sets/hp1991_text_{a,b,c}.csv (правила — sets/READING.md);
#    стыки множества: разрез над блоком, «один блок» внутри подписи и над ней
uv run python -m research.flush_split joints --drafts sets/hp1991_text_a.csv --drafts sets/hp1991_text_b.csv \
    --drafts sets/hp1991_text_c.csv --out research/flush_split/sets/hp1991_joints.csv
# 4. разбор способами (по множеству или всем вырезкам)
uv run python -m research.flush_split run --pages research/flush_split/sets/hp1991_joints.csv \
    --modes align_gap,align_right --out /mnt/hotstore/scan_processing/block_split/v7/set.jsonl
# 5. оценка и листы промахов
uv run python -m research.flush_split evaluate --joints research/flush_split/sets/hp1991_joints.csv \
    --runs .../set.jsonl --misses .../misses.csv
uv run python -m research.flush_split sheets --joints ... --runs .../set.jsonl --misses .../misses.csv
# 6. все вырезки: изменённые стыки «было | стало» вне множества — на отсмотр
uv run python -m research.flush_split compare --before .../all_gap.jsonl --after .../all_right.jsonl \
    --joints research/flush_split/sets/hp1991_joints.csv
```

## Множество (`sets/`)

- `hp1991_text_{a,b,c}.csv` — разметка по тексту tesseract: блок (подпись, город, эпиграф, прочее вправо), его
  первая строка (y, мм), число строк, стоит ли под абзацем. Читали субагенты по `READING.md`, без регулярок.
- `hp1991_joints.csv` — стыки: `cut` над первой строкой блока, `keep` между строками блока (`*_inner`) и между двумя
  последними строками абзаца над ним (`paragraph_inner`). 818 стыков, 237 страниц.
- Шум разметки: tesseract сливает строки и путает колонки (пометка `?` в `note`); 76 из 81 `right_other` — рубрики
  вверху страницы без абзаца над ними (ряда сверху нет — в оценку не входят).

- Все 1106 вырезок, `align_gap` → `align_right`: 92 новых разреза, 38 склеек, 78 страниц. 31 изменение вне множества
  отсмотрено глазами (`compare`): верные — подписи читателей и город (01/IMG_1075_L, 02/IMG_1181_R), «Фото В.
  Дронова» (04/IMG_0154_L), подпись под законом (07/IMG_0068_R), заголовок статьи (07/IMG_0068_R), фамилия с регалией
  (03/IMG_0077_L); шум — рубрики на полях оглавлений, таблицы и формулы (стенд без подсказок surya, в v2 таблицы

- Оставшиеся промахи подписей — в основном шум разметки tesseract (строка с фамилией не прочитана, колонки спутаны)
  и подписи, стоящие влево; города, слитые в одну строку с регалией (7), не режутся.
