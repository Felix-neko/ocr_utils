# research/edge_sharpen — заострение края листа перед SAM 3

**Задача.** В ПХ (пак-4, 1975) и МТС 1990 (паки 5–6) край верхней страницы часто почти сливается с торцами нижних
листов: SAM 3 берёт край волной — то по верхней странице, то по нижним листам, — и v2 даёт незаслуженно рваную или
волнистую сторону. Проверено, помогает ли фильтр кадра сегментации перед SAM 3 (и перед доводкой края).

Боевой `ocr_utils/scan_cropping/v2` не тронут: стенд берёт кэш прогонов v2 (`seg.png`, `seg_noink.png`, `book.npz`,
`fingers.npz`), прогоняет SAM 3 (оба прохода) по отфильтрованному кадру и повторяет `cpu_pages` с ключами боевых
прогонов (`--fit-sides`, `--no-snap-sides`, цветные страницы, глубина уточнения 5.07 мм).

## Запуск

```bash
run_scripts/scan_cropping/run_edge_sharpen_set.sh   # ~15 мин: SAM 3 (GPU, последовательно), бумага, меры, листы
```

Команды: `run` (SAM 3 + бумага в двух режимах), `measure` (`measures.csv`), `sheets` (вырезки спорного края).
Выход: `$EDGE_SHARPEN_ROOT=/mnt/hotstore/scan_processing/edge_sharpen/`
(`<фильтр>/<прогон>/<ключ>/{sam3.npz,paper_{sam,all}.npz,pages_{sam,all}.json}`, `measures.csv`,
`sheets/{sam,all}/<прогон>__<ключ>.jpg`; кандидаты отбора — `select/`).

## Наборы

- `sets/ragged.txt` — 18 кадров: волна дальней стороны + 3 × рваность по мерам `research/page_cutting` (плоские
  развороты), плюс примеры пользователя ПХ 01/IMG_0046, 01/IMG_0048, 03/IMG_0007, 08/IMG_0055.
- `sets/control.txt` — 5 кадров с самыми ровными краями.

## Фильтры (`filters.EdgeFilter`, размеры в мм бумаги, масштаб сегментации 6.9 px/мм)

`none` (повтор SAM 3 без фильтра), `unsharp_fine` (0.5 мм ×1.5), `unsharp_wide` (2 мм ×1.0), `clahe` (L в Lab, клетка
20 мм, предел 3), `detail` (`cv2.detailEnhance`, σs 1.5 мм), `bilateral_unsharp` (bilateral 1 мм + нерезкая 1 мм),
`morph_gradient` (L − 1.5 × морфологический градиент 0.6 мм), `gamma` (1.8 по L).
Режимы: `sam` — фильтр только во вход SAM 3; `all` — и в доводку края (snap, склейка, уточнение, стороны).

## Меры (`measure.py`)

По наружным сторонам страниц (верх, низ, дальняя; корешок — не мерится): рваность — 90-й перцентиль отклонения
контура от медианно сглаженного (15 мм) профиля стороны; волна — размах сглаженного профиля; площадь бумаги.
«Лучше / хуже» — сумма «рваность + волна дальней» меньше / больше, чем у v2, больше чем на 0.5 мм.

## Итоги (медианы; набор ragged — 18 кадров, control — 5)

| вариант (режим sam) | рваность, мм | волна дальней, мм | волна в/н, мм | Δ площади | лучше | хуже |
|---|---|---|---|---|---|---|
| v2 = none (SAM 3 детерминирован) | 1.06 | 8.26 | 3.04 | 0 | — | — |
| **clahe** | **0.64** | **5.65** | 3.33 | +0.01 % | **13** | **0** |
| gamma | 0.68 | 4.86 | 3.19 | −0.36 % | 12 | 3 |
| morph_gradient | 0.72 | 4.17 | 3.07 | −0.27 % | 11 | 3 |
| detail | 0.81 | 6.22 | 3.08 | +0.11 % | 11 | 2 |
| unsharp_wide | 0.75 | 7.44 | 3.58 | +0.26 % | 8 | 4 |
| unsharp_fine | 0.75 | 7.40 | 2.85 | −0.02 % | 7 | 4 |
| bilateral_unsharp | 0.73 | 7.40 | 3.45 | −0.01 % | 6 | 4 |

Контроль: ни один фильтр не ухудшил ни одного кадра (рваность 0.21–0.30 мм, волна 1.1–1.25 мм, площадь ±0.4 %).
Режим `all` почти не отличается от `sam` (clahe: 13/0 в обоих) — фильтр нужен только во входе SAM 3.

## Глазами (листы `sheets/sam/`)

- **clahe** — самый ровный: на ПХ 04/IMG_0043 волна 11.4 → 2.7 мм, край ложится прямой линией по краю верхней
  страницы, торцы нижних листов отрезаны; ПХ 01/IMG_0048 — «язык» на нижние листы ушёл; пак-5 0370, 0450, 0070 —
  волна 8–9 → 2–5 мм. Не помогает там, где v2 и так шёл по краю верхней страницы, а волну даёт закруглённый угол
  (пак-5 0510, 0390).
- **gamma** — часто так же хорошо (0510: 9.2 → 2.5 мм), но местами переходит на край соседнего нижнего листа
  (0370: волна 9.3 мм, 0070: рваность 1.8 мм).
- **morph_gradient** — на пак-5 0260 уходит на внешний край торцов нижних листов (ровно, но не тот край); буквы
  жирнеют.
- **unsharp / bilateral / detail** — на ПХ 04/IMG_0043 и 01/IMG_0048 захватывают торцы нижних листов кривыми языками.

## Вывод и рекомендация

CLAHE по светлоте (клетка 20 мм, предел 3) только во входе SAM 3 — единственный вариант без ухудшений на наборе:
13 из 18 рваных кадров ровнее, контроль не тронут, площадь бумаги в среднем та же. Кандидат на перенос в v2 — как
ключ (`--sam3-clahe`) или как третий проход SAM 3 с выбором по стороне: брать сторону страницы того прохода, у
которого она ровнее (v2 и clahe дополняют друг друга, gamma — третий кандидат). Перед переносом — прогон по паку
целиком и отсмотр по поясам меры (набор из 18 кадров для порогов мал), особенно цветных страниц (CLAHE меняет
светлоту, а `colour_pages` смотрит палитру — здесь фильтр в доводку не подавался).

Не сделано: выбор прохода по стороне (ансамбль), подбор параметров CLAHE (клетка, предел), прогон по паку целиком.
