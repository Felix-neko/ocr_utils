
Теперь пора сделать скрипт, который будет собирать финальные PDF

На вход подаётся:
- путь к папке с бинаризованными PDF с текстовым слоем с коррекцией геометрии;
- путь к папке с бинаризованными PDF с текстовым слоем без коррекции геометрии;
- путь к папке с выходными PDF
- путь к папке с картинками (в нашем случае это sharpened-картинки пака-1)
- путь к sqlite-базе с информацией по нашему паку (БД выбираем - которая "после экспорта из CVAT").
- коэффициент JPEG-сжатия вставляемых растровых изображений
- DPI вставляемых растровых изображений (я думаю про 300 DPI)
- опционально: year-only и issue-only

При сборке финальной PDF для каждой PDF будем делать следующее.

Перед сборкой проверять, что в обоих входных папках имена и количества страниц в PDF совпадают.

Для каждой PDF по каждой странице делать следующее.
1) Определиться, нужна ли нам страница с коррекцией геометрии -- или без неё. 
  1.1) Обратиться к БД и проверить: нет ли на этой PDF растровых изображений или областей цветного текста. Если есть -- выбираем из входной PDF страницу без коррекции геометрии.
  1.2) Вызвать детектор ухудшения геометрии после коррекции геометрии FineReader: если он показывает, что FineReader ухудшил геометрию страницы -- выбираем страницу без коррекции геометрии.
  1.3) Иначе -- выбираем страницу из PDF с коррекцией геометрии.
3) Делаем для этой страницы обнаружение некорректных распознаний текста (см /reports/text_layer_fix.md) и их коррекцию (т.е. для случаев повёрнутого текста и для случаев ненахождения FineReader неповёрнутого текста).
2) Если на странице есть области растровых изображений (области получаем из БД) -- вставляем их в PDF отдельным верхним слоем как растровые изображения. Нужно при этом учесть ориентацию страницы (есть в БД) и то, какие поля мы добавляли при создании промежуточных PDF (не помню, где хранится эта инфа).
 Желательно также, чтобы при вставке растровых изображений grayscale-изображения вставлялись как одноканальные. Желательно также затереть область бинаризованного изображения под этими растровыми изображениями, чтобы слегка выиграть в размере PDF. Делать ли какую-то дополнительную обработку картинок при уменьшении DPI, чтобы не было муара и эффекта растра -- проверь и реши сам (если решишь делать, сделай это настраиваемым).
