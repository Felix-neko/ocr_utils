 Похоже, мы перегрузили нашу VLM. Предлагаю тогда делать так:                                                                      
  - два отдельных способа распознания:                                                                                              
    - для страниц с оглавлением - полного содержания вообще не извлекать, только <toc>-секцию с рубриками, статьями и авторами, а   
  также поле "точно ли это оглавление" и поле, которое говорит, есть ли там заголовок самого оглавления;                            
    - для обычных страниц - нормальный md-контент + поле, которое говорит, не является ли страница оглавлением;                     
                                                                                                                                    
  Этап 0 (страницы с оглавлением, пришедшие из моей разметки): для них мы делаем распознание по сценарию "оглавление".              
  Этап 2: все страницы выпуска, включая страницы оглавлений, отправляем на распознание по сценарию "страница".                      
  Этап 3: если по итогам этапа 2 выявлено новое оглавление или старое оглавление demoted -- тогда делаем повторное распознание      
  страниц с рубриками, авторами и с <markers> (чтобы лишние header 1 понищзить, новые имена авторов пометить как авторов, новые     
  имена статей пометить как header 1, возможные имена рубрик, если найдём их в новом заголовке, пометить как имена рубрик).         
                                                                                                                                    
                                                                                                                                    
  Перед реализацией -- проверь, что такое "упрощённое" распознание по сценарию "оглавление" даёт теги без сбоев.
