# zonal_deblur — снятие зонального смаза

Исправляет сканы, у которых резкость неровная по кадру: одна часть разворота
чёткая, другая смазана. Типичная причина — перекос камеры или неплотно прижатая
страница, из-за чего часть листа уходит из плоскости фокуса, а дрожание камеры
добавляет направленный смаз.

## Как это работает

1. **Эталон.** Берутся самые резкие окна самого же скана (верхние 15% по дисперсии
   лапласиана) и по ним считается усреднённый спектр мощности.
2. **Оценка.** Кадр делится на сетку. Для каждой ячейки считается отношение её
   спектра к эталонному, и в это отношение вписывается анизотропный гауссиан
   `|K(f)| = exp(-2π²(σ_a²f_a² + σ_b²f_b²))`. Получается *относительная* PSF — то
   ядро, которым резкая часть кадра превращается в эту ячейку.
3. **Деконволюция.** Каждая ячейка разворачивается фильтром Винера, результаты
   складываются с весами-«домиками», дающими в сумме единицу. Швов между зонами
   не возникает.

Разворачивается только яркость (Y из YCrCb): детали живут в ней, а цветовые каналы
трогать незачем — иначе по краям букв пойдёт цветная бахрома.

## Чего инструмент не делает

Резкость **выравнивается по кадру**, а не улучшается вообще. Эталон берётся из
самого скана, поэтому равномерно мягкий кадр останется равномерно мягким: сравнивать
не с чем. Для такого случая есть `--extra-sigma`, который добавляет изотропную
резкость всем ячейкам, включая эталонные, — но это уже обычное шарпенье, а не
восстановление по измеренной PSF.

## Использование

```bash
# посмотреть, что за размытие в кадре, ничего не записывая
python -m ocr_utils.zonal_deblur scan.tiff --dry-run

# исправить
python -m ocr_utils.zonal_deblur scan.tiff -o scan_fixed.tiff
```

Размер сетки по умолчанию подбирается по размеру кадра, ячейка около 650 px.
Мельче сетка — точнее у самого края, но в ячейку попадает меньше окон и оценка
шумит. На развороте 3843×2927 сетка 6×4 сняла смаз вчетверо лучше, чем 4×3.

Полезные ключи:

| Ключ | Смысл |
| --- | --- |
| `--dry-run` | только оценить и напечатать таблицу |
| `--nsr` | шум/сигнал для Винера; меньше — агрессивнее, но лезет зерно |
| `--method rl` | Ричардсон—Люси вместо Винера |
| `--extra-sigma` | дополнительная резкость по всему кадру |
| `--smooth` | сглаживание оценок по соседним ячейкам, 0..1 |
| `--rows`, `--cols` | задать сетку вручную |

## Как читать таблицу

```
  ячейка   sigma_max  sigma_min   угол   окон   невязка
  r1c0        0.86       0.18     44°     81      280.4
```

`sigma_max` при `sigma_min` около нуля — направленный смаз, и `угол` показывает,
куда. Если обе сигмы примерно равны, это расфокус. Большая `невязка` означает, что
гауссова модель ячейке не подошла: обычно там мало текста или он другого кегля.

## Проверка

`--dry-run` по обработанному файлу — самый прямой способ убедиться, что смаз снят:
разброс `sigma_max` по ячейкам должен сжаться. Учтите только, что эталон
пересчитывается по обработанному кадру, поэтому абсолютные числа двух прогонов
между собой несравнимы — смотреть надо на разброс.

## Грабли, на которые уже наступили

**Дискретизация ядра.** Гауссиан с поперечной сигмой меньше пикселя, посаженный на
целочисленную сетку, выходит уже заказанного: заказ `(1.0, 0.15)` даёт фактический
второй момент 0.87. Поэтому деконволюция строит передаточную функцию аналитически
(`gaussian_otf`), а не через БПФ выборки ядра. На этом же легко обмануться при
проверке: сравнивать оценку надо с фактическим вторым моментом ядра, а не с тем,
что заказывали.

**Множитель усиления.** Он вырожден с ослаблением на низких частотах. Свободный
множитель забирает размытие себе и занижает оценку почти вдвое — отсюда привязка
отношения к единице на низких частотах и узкий допуск `GAIN_BOUND`.

**Метрики резкости на разном содержимом врут.** Дисперсия лапласиана двух половин
разворота отличается и просто из-за разной плотности набора. Оценка через отношение
спектров к общему эталону от этого защищена, а «сравню-ка я лапласианы» — нет.
