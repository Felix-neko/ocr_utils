# Прежняя сцепка кусков строк: жадная цепочка и поле хода строк

Оставлена рабочей ради сравнения: `--linking greedy` возвращает разбор к ней целиком. Рабочий
ход — `ocr_utils/curved_layout/zones.py`.

## Как работала

`linking.link_spans` растила цепочку слева направо: от последнего куска бралcя ближайший справа,
у которого ордината не расходится с ПРЕДСКАЗАНИЕМ по последним шести звеньям (прямая через них),
разрыв не больше 2.5 высот, высоты соседей различаются не больше чем в 1.8 раза, между кусками
нет живого межколонника.

`baselines.field_of` оценивала по длинным строкам первого прохода поле НАКЛОНА набора (RBF
`thin_plate_spline` по сетке 32×48) и выпрямляла ординаты интегрированием `y' = y − ∫tgθ dx`.
Второй проход повторял ту же сцепку с полем как ограничителем, а `merge_by_field` сшивала
цепочки, лежащие на одном уровне поля.

## Почему заменена

Беда накопительная, а пороги локальные. На искажённой бумаге сгустки соседних строк ЧЕРЕДУЮТСЯ
по x (замер на 1973/08 с.85: ряд ординат 1200, 1226, 1204, 1232, 1209, 1234), каждое отдельное
звено законно — излом внутри цепочек имеет медиану 1.6° и максимум 10°, наклоны звеньев 1.2° и
11°, то есть от нормальных неотличимы, — а за пять звеньев ось уходит на соседнюю строку.

Поле этого не чинит: оно правит ОБЩИЙ ход полосы, сдвигая ординаты на 1.3 px по медиане и на
3.8 px в максимуме при полушаге строк 11.9 px. Местный изгиб в углу полосы ему не по силам, и на
той самой странице ограничитель не изменил ни одной цепочки (211 против 211).

Замеры по текстовому валидационному набору (12 полос × 2 варианта рендера), жадный ход против
зон: сближений осей 11 → 7, осей с отклонением от хорды больше полушага 26 → 22, рядов-половинок
30 → 28, осей вне контуров блоков 0 → 0, покрытие краски 99.2 → 99.1 %, время 38 → 35 с.

## Что здесь лежит

* `linking.py` — `link_spans`, `merge_by_field` и их пороги;
* `baselines.py` — поле хода строк (`LineField`, `field_of`, `anchors_of`, `slope_samples`).

Мёртвая ветка сверки с наклоном соседних строк (параметр `slopes`, `_local_slope`) при переносе
удалена: он никогда не передавался.
