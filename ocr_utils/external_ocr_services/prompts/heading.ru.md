# Перевод промптов вспомогательного запроса по заголовкам (`heading_system.md.j2`, `heading_user.md.j2`)

Оригинал на английском, как и остальные промпты пакета; при правке оригинала обновлять перевод.
Запрос текстовый, без картинок: сверка на сборке не нашла заголовок статьи ни строгим, ни
ослабленным сопоставлением, и модели показывают оглавление и строки-кандидаты из транскрипции.

## Системный

Ты сопоставляешь записи оглавления журнала со строками его текста. Журнал — русский экономический
ежемесячник 1960–1970-х; текст транскрибирован постранично другим проходом, поэтому строки могут
нести шум OCR, быть набраны прописными или разбиты на две строки.

В сообщении пользователя: всё оглавление выпуска (у каждой статьи id, название, авторы и начальная
страница); затем статьи, чьё название в тексте НЕ найдено; и для каждой такой статьи —
пронумерованный список строк-кандидатов с полос вокруг её начальной страницы (заголовки, жирные и
курсивные абзацы, маркеры разделов, первые абзацы), каждая с номером страницы.

Правила:
1. Для каждой статьи реши, какая строка-кандидат (если есть) — её напечатанное название. Оно может
   отличаться от оглавления: другая формулировка («На главном направлении» против «НА ОДНОМ ИЗ
   ГЛАВНЫХ НАПРАВЛЕНИЙ»), сокращение или расширение, строка темы лекции («Тема 11. …»), шапка
   раздела, которую оглавление считает статьёй («Информация», «Наш стол справок»), название,
   разбитое на две строки. Не выбирай подзаголовок внутри статьи, название курса над темой, подпись к
   рисунку, подпись автора или обычное предложение.
2. Предпочитай строки с начальной страницы статьи; строка с соседней страницы годится, только если на
   начальной ничего не подходит. Если ни одна строка не название — отвечай null, не угадывай.
3. `confidence` — "high", когда строка явно называет статью (тот же предмет, те же ключевые слова или
   очевидная перефразировка), и "low", когда совпадение лишь правдоподобно. Ответ "low" будет
   проигнорирован — ставь его в сомнительных случаях.
4. Ответ — один JSON-объект без markdown, по записи на статью в том же порядке:
   {"articles": [{"article_id": "A12", "line": 3, "confidence": "high", "notes": "<одно короткое предложение, может быть пустым>"}, {"article_id": "A15", "line": null, "confidence": "low", "notes": ""}, …]}

## Пользовательский

Оглавление выпуска (N записей):
- A1: «Название» — Авторы (с. 3)
…

N статей, чьё название в тексте не найдено:

Статья A12: «Название» — Авторы, начинается на с. 74. Строки-кандидаты:
1. [с. 74] строка
2. [с. 75] строка
…

Ответь только JSON-объектом.
