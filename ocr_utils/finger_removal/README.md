# finger_removal — удаление пальцев со сканов газетных/журнальных полос

Подпакет убирает пальцы/большой палец, которым придерживают разворот при съёмке,
и дорисовывает то, что было под ними (фон, переплёт, поле бумаги).

Вход — PNG-сканы (~3000×4300, RGB 8-бит), где палец входит в кадр **с края**
(чаще на левых страницах `*_1L`, реже снизу/справа). Выход — те же PNG без пальцев.
На кадрах без пальцев маска пустая и изображение копируется **без изменений**
(пиксель-в-пиксель).

```
uv run python -m ocr_utils.finger_removal ВХОД ВЫХОД                 # дефолт: edge
uv run python -m ocr_utils.finger_removal ВХОД ВЫХОД --mask-only --debug-dir ВЫХОД/dbg
uv run python -m ocr_utils.finger_removal ВХОД ВЫХОД --inpaint-method lama
```

## Конвейер

```
PNG → маска пальца (нейросеть + цвет кожи) → инпейнтинг области → вклейка с растушёвкой → PNG
```

Модули:
- `masking.py` — построение маски пальца.
- `inpainting.py` — заполнение области маски (edge/vertical/horizontal/lama/sd) и вклейка.
- `__main__.py` — CLI (`click`) и оркестрация: цикл по файлам, debug-оверлеи, ручные маски.

Веса нейромоделей качаются автоматически один раз в `finger_models/` (корень
проекта): YOLO-World, SAM (для маски) и big-lama (для `--inpaint-method lama`).
SD-модель — в кэш HuggingFace.

## 1. Маскирование (`masking.py`, `build_finger_mask`)

Палец нужно отделить от похожих по цвету бумаги/переплёта. Используем связку
«нейросеть как семантический затвор + цвет кожи для добора краёв».

**Нейродетектор (`neural_hand_mask`)**: open-vocabulary YOLO-World по классам
`hand/finger/thumb/...` даёт боксы → SAM по боксам даёт точный силуэт. Отбраковка:
боксы крупнее `max_box_frac` кадра и SAM-маски крупнее `MAX_FINGER_AREA_FRAC`
(=0.12) — палец не занимает половину снимка. Класс «person» НЕ используем: он
матчит всю страницу и даёт огромные ложные маски.

**Скин-прайор (`skin_color_mask`)**: кожа в YCrCb (классич. диапазон) ∩ HSV
(тёплый красно-розовый оттенок, насыщенность ≥55 — чтобы НЕ цеплять бледную
кремовую бумагу).

**Сборка (`build_finger_mask`, режим `auto` — по умолчанию):**
1. `nm` = нейромаска. Если пусто → маска пустая (палец считаем отсутствующим;
   на кадрах без пальца не выдумываем).
2. `sm_near` = скин-компоненты, **пересекающиеся с `nm`** (`keep_seeded_components`).
   Это мягкие края/ноготь, которые детектор недобрал. ⚠️ Важно: берём именно
   пересечение с нейромаской, а НЕ «касание края кадра» — иначе цветная кромка
   бумаги у края (на правых страницах) ложно попадает в маску и лезет на текст.
3. `mask = nm ∪ sm_near`, затем `fill_holes` (силуэт сплошной) и дилатация
   (`--dilate`, по умолч. 14) для захвата мягкого гало.

Режимы `--mask-method`:
- `auto` — нейросеть + добор кожей (рекомендуется);
- `neural` — только YOLO-World→SAM;
- `skin` — только цвет кожи (склонен к ложным срабатываниям на бумаге).

**Отладка/ручной режим:** `--mask-only` строит только маски; `--debug-dir`
сохраняет `*_overlay.png` (маска поверх кадра) и `*_mask.png`; `--mask-dir`
подкладывает заранее нарисованные вручную маски там, где автоматика ошиблась.

## 2. Инпейнтинг (`inpainting.py`, `inpaint_image`)

### `edge` — продолжение кромки книги (метод по умолчанию)

Ключевое наблюдение: палец входит **с края**, а вдоль кромки книги содержимое
(чёрный фон, мраморный переплёт, поле бумаги) **постоянно вдоль этого края**.
Значит область можно заполнить продолжением соседних линий — точно «как было»,
без выдумок и без чёрной заливки.

**Выбор оси — покомпонентно** (`edge_inpaint` → `dominant_fill_axis`):
для каждой связной компоненты маски (каждого пальца) считаем, какой границы кадра
она касается сильнее (`border_contact`):
- касание левой/правой кромки больше → полосы вертикальные → заполняем вдоль
  **колонок** (`vertical`);
- касание верхней/нижней кромки больше → полосы горизонтальные → заполняем вдоль
  **строк** (`horizontal`).

Покомпонентность нужна, когда **разные пальцы входят с разных краёв** (один сверху,
другой сбоку) — каждый заполняется по своей оси.

**Само заполнение** (`_fill_along_columns`): для каждой колонки (или строки —
через транспонирование) берём немаскированные пиксели как опорные и линейно
интерполируем (`np.interp`) значения замаскированных. Опорой служат только пиксели
вне **любой** маски (чтобы не интерполировать по коже соседнего пальца). На краю
интерполяция зажимается к крайнему опорному значению (копия края). Текстура слегка
вытягивается в штрихи вдоль оси — читается как продолжение кромки.

`--inpaint-method vertical` / `horizontal` — та же логика с принудительной осью.

### `lama` / `sd` — нейросетевые (ROI вокруг всей маски)

- `lama` — big-LaMa (torchscript, грузится напрямую). Хорош на текстурах, но рядом
  с большой чёрной зоной **заливает область чёрным** (теряет тонкий переплёт).
- `sd` — Stable Diffusion inpainting (diffusers). На структурной кромке
  **галлюцинирует** (выдумывает наклейки/текст). Параметры против лишних деталей:
  низкий `--sd-guidance`, анти-пятенный негатив-промпт, пост-сглаживание
  `--sd-smooth` (edge-preserving). Модель по умолчанию
  `stable-diffusion-v1-5/stable-diffusion-inpainting` (ungated).

### Вклейка

Полноразмерное «заполненное» изображение подмешивается к оригиналу по
растушёванной альфе маски. Внутри маски **альфа=1** (полный инпейнт), мягкий спад
гауссом — **только наружу**; иначе у внутренней кромки подмешивался бы исходный
пиксель кожи → розовое гало.

## Опции CLI (основные)

| Опция | По умолч. | Назначение |
|---|---|---|
| `--mask-method` | `auto` | `auto` / `neural` / `skin` |
| `--inpaint-method` | `edge` | `edge` / `vertical` / `horizontal` / `lama` / `sd` |
| `--dilate` | `14` | дилатация маски, пикс. |
| `--padding` | `96` | контекст вокруг компоненты/ROI, пикс. |
| `--mask-only` | — | только маски/оверлеи, без инпейнтинга |
| `--mask-dir` | — | каталог ручных масок `<stem>.png` |
| `--debug-dir` | — | куда сохранять оверлеи/маски |
| `--sd-guidance` / `--sd-smooth` / `--sd-steps` / `--sd-prompt` / `--sd-model` | | параметры SD |

## Почему `edge` — метод по умолчанию (выводы из экспериментов)

На этих сканах палец лежит на **структурной кромке** (чёрный фон | мраморный
переплёт | поле | текст), и универсальные инпейнтеры там слабы:
- **LaMa** заливает область **чёрным** (проверено даже с полным контекстом кадра) —
  врождённое поведение рядом с большой чёрной зоной.
- **SD** **галлюцинирует** наклейки/текст на переплёте даже при низком guidance —
  диффузия генерит структуру в большой маске.
- **`edge`** использует геометрию задачи (кромка = полосы, постоянные вдоль края)
  и восстанавливает их «как было», без выдумок. Плюс он почти мгновенный (время
  прогона определяется этапом нейромаски).

`lama`/`sd` оставлены доступными через флаг для нетипичных случаев.
