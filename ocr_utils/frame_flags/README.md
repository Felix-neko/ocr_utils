# ocr_utils/frame_flags — флаги кадра в сайдкаре

Нестандартный кадр фото-разворота получает рядом с собой сайдкар `<полное имя кадра>.flags.json`. Обычный кадр
сайдкара не получает. Флаги читает `scan_cropping.v2`. Размечает папки Claude по навыку `.claude/skills/frame-flags`.

## Схема

```json
{
  "schema": 1,
  "flags": ["ignore-right"],
  "note": "библиотечная карточка закрывает правую страницу; правая плоско — IMG_0006.jpg",
  "pair": "IMG_0006.jpg",
  "reviewed": "2026-10-23"
}
```

| Флаг | Что значит для v2 |
|---|---|
| `ignore-both` | кадр не обрабатывается вовсе (обложка и форзацы подшивки) |
| `ignore-left` / `ignore-right` | страница не пишется в `--output-pages`, в поле выпрямления не участвует; разворот в основном выходе пишется как обычно |
| `no-splitting` | разворот выпрямляется, но не режется: один файл `<кадр>_LR` |
| `no-illumination-left` / `-right` | без выравнивания освещения у этой страницы (прежнее имя `no-color-equalize-*` читается так же) |
| `no-text-rectify-left` / `-right` | страница не выпрямляется по строкам (второе преобразование, поле по тексту); Кунс по краям листа остаётся. Передняя обложка, страница-картинка |
| `cover-left` / `cover-right` / `cover-both` | страница — обложка своего номера: в `scan_markup` зона контента равна рамке страницы (обрезки нет). Освещение и выпрямление строк флаг не выключает: у передней обложки их выключают `no-illumination-*` и `no-text-rectify-*`, задней с анонсом книг строки выпрямлять нужно |
| `single-page` | в кадре одна страница (обложка выпуска, снятая отдельно; страница «фото по страницам»): не резать, писать одной страницей `<кадр>_P`. Перекрывает автомат `scan_cropping/v2/single_page.py`. Нельзя вместе с `ignore-left/right`, `no-splitting`, `cover-left/right`, `spread`; обложка — `cover-both` |
| `spread` | кадр — разворот: автомат «одна страница» на нём выключен (страховка от ложного срабатывания) |

Как устроены проверки:

- Новый флаг добавляется значением в `FrameFlag` (`flags.py`). Его смысл описывается здесь и в v2.
- Неизвестный флаг — ошибка, а не молчание.
- `ignore-left` и `ignore-right` вместе сводятся к `ignore-both`, `cover-left` и `cover-right` — к `cover-both`.
- `no-splitting` нельзя сочетать с игнорированием одной стороны.
- `schema` новее поддерживаемой — ошибка.

Имя сайдкара включает расширение кадра, поэтому `.jpg` и `.tif` с одной основой не путаются. `collect_images` сайдкары
не подхватывает.

## Запись на Я.Диск

Папки кадров лежат под корнем живой синхронизации Я.Диска. По `docs/data_layout.md` туда можно писать только сайдкары
и только командами `write` и `remove`:

- `write` создаёт только `*.flags.json` и сам кадр не трогает;
- существующий сайдкар без `--replace` не перезаписывается;
- листы и CSV под Я.Диском команды писать отказываются;
- хук `guard_bash.py` блокирует запись туда через `cp`, `>`, `tee`, `touch`.

## Команды

```bash
uv run python -m ocr_utils.frame_flags sheets --input-dir "<папка>" --out-dir <scratch>/sheets   # миниатюры по 20, с флагами
uv run python -m ocr_utils.frame_flags neighbors --input-dir "<папка>" --out <scratch>/neighbors.csv [--jobs 12]
uv run python -m ocr_utils.frame_flags pair-sheet A.jpg B.jpg --out <scratch>/pair.jpg [--width 1600]
uv run python -m ocr_utils.frame_flags write "<папка>/IMG_0005.jpg" --flag ignore-right --note "…" [--pair IMG_0006.jpg] [--replace]
uv run python -m ocr_utils.frame_flags remove "<папка>/IMG_0005.jpg"
uv run python -m ocr_utils.frame_flags show --input-dir "<папка>" [--recursive]
```

`neighbors` сравнивает кадры через 1 и 2 по порядку имён: AKAZE на серой копии шириной 1400 px, гомография RANSAC.
Папка из 80 кадров считается примерно за 10 с при 12 воркерах. Колонки CSV:

- `share` — инлаеры, делённые на меньшее число точек пары;
- `share_left` и `share_right` — доли инлаеров среди совпадений в половинах первого кадра;
- `shift_px` — сдвиг центра кадра.

Что показали ПХ пак-4 1974/01–02 и ХиП 1977/01:

- фон стола и подшивки даёт `share` от 0.01 до 0.05;
- повторная съёмка разворота даёт от 0.1 до 0.6 (1974/01 IMG_0005/0006 — 0.51, ХиП 0619/0622 — 0.17);
- доли по половинам — только подсказка (в ХиП 0622 поднята левая, а у левой доля 0.95). Решение принимается глазами
  по `pair-sheet`.

Тесты: `uv run pytest tests/ocr_utils/frame_flags -q`.
