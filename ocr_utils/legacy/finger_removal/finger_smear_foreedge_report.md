# Артефакт закраски пальца на обрезе книжного блока (IMG_0088)

**Дата:** 2026-07-23
**Кадр:** `/mnt/system/raw/ve_test/out/1962/02/IMG_0088.tiff`
(вход: `.../неразобранное/2026-13-07-ВЭ/1962/02/IMG_0088.jpg`,
debug-оверлей: `/mnt/system/raw/ve_test/debug/1962/02/IMG_0088.jpg`)
**Конфиг прогона:** `run_detect_and_crop_ve_k48.sh` (dilate-px=120, max-asymmetric-dilation-ratio=1.6,
protect-text-layout + copy-back-layout-zones, bg-fill=nearest).

## Симптом

На левом и правом краях, где лежали большие пальцы, LaMa оставил размазанные
веерообразные («звёздчатые») пятна вместо текстуры бумаги/обреза. Палец убран
корректно, но заливка на его месте — очевидное пятно (радиальная «вспышка»).

## Диагноз (по замерам, не на глаз)

1. **Детекция пальца точная.** Красный тонкий пунктир на оверлее (SAM, ДО
   дилатации) лежит ровно по пальцу.

2. **Пятно раздувает асимметричная дилатация, а не боксы YOLO.** Маска пальца
   растёт по площади **×2.72** (predilate 655k px → dilated 1.78M px). Для
   бокового пальца (левый/правый край, середина по вертикали) асимметрия льёт
   рост **по вертикали** (`y_ratio = 1 + max_ratio`, при ratio=1.6), то есть
   ВДОЛЬ обреза — ровно в плохую фактуру. См. `asymmetric_dilation.py`.

3. **Почему именно «веер».** Раздутая дырка накрывает сразу три несовместимые
   фактуры: плоскую страницу, полосатый обрез книжного блока (стопка торцов
   листов) и тёмный зазор фона. LaMa не восстанавливает высокочастотный
   направленный рисунок обреза и на большой дыре у резкой направленной границы
   выдаёт гладкую радиальную «вспышку».

4. **Вертикальные стопки YOLO-боксов на обрезе — только debug, в LaMa не идут.**
   YOLO выдал 15 боксов, но после нейромаски руки + `keep_border_components`
   в маску закраски попали ровно **2 компоненты** (два пальца). То есть
   «подавлять боксы на обрезе» (идея №3) отдельно не нужно — они уже отсеяны
   до закраски.

5. **Расклад маски относительно силуэта страницы (E1):** из маски закраски
   **68% внутри силуэта, 32% вне** (на тёмном зазоре фона). Важно: яркий обрез
   книжного блока SAM включает ВНУТРЬ силуэта.

## Ограничение текущего порядка

Закраска пальцев выполняется ДО `page_mask` намеренно (docstring `remove_fingers`:
палец искажает детекцию разворота и кроп). Поэтому идеи «клипить по силуэту» и
«давить боксы на обрезе» упираются в то, что силуэта на момент закраски ещё нет.

Проверено: `page_mask`, посчитанный С пальцем в кадре, даёт устойчивый силуэт
(слегка вдавленный вокруг пальца) — то есть развязать порядок можно
**двухпроходно**, без потери качества силуэта.

## Возможные меры (не реализованы — на потом)

1. **Идея №3 (давить боксы на обрезе) — не требуется:** уже отсеиваются
   нейромаской руки + `keep_border_components`.

2. **Идея №2 (клип по силуэту) — частична.** Двухпроходно: `page_mask` по
   кадру-с-пальцем → обрезать дилатированную маску этим силуэтом → закрасить →
   финальный `page_mask` по чистому кадру. Цена: +1 проход детекции (~1.2 с/кадр).
   Уберёт только фоновый «хвост» дырки (те 32% на тёмном зазоре — источник самой
   злой вспышки на границе светлое↔чёрное). **Яркий обрез внутри силуэта клип НЕ
   пощадит** — его надо спасать отдельно.

3. **Ограничить асимметричный рост** у границы силуэта, чтобы пузырь не растекался
   ×2.7 вдоль обреза (главный источник большой дыры).

4. **Быстрый эксперимент без перестройки порядка:** просто снизить
   `--finger-dilate-px` и/или `--max-asymmetric-dilation-ratio` на таких кадрах и
   посмотреть, насколько уменьшится пятно.

5. **Обрез книжного блока** (полосатая фактура) фундаментально тяжёл для LaMa при
   большой дыре — либо не раздувать маску на него, либо edge-aware заливка полос.
